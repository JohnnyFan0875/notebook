# Rendering

Rendering refers to how the browser transforms application code into a visible UI.

Rendering types:

- Static Rendering: HTML generated once during build time.
- Client-Side Rendering (CSR): HTML generated dynamically in the browser.
- Server-Side Rendering (SSR): HTML generated by the server before being sent to the client.
- Hydration: Process of attaching React’s event handlers to static HTML after initial load.
