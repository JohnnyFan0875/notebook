# CSR, SSR, SEO

Client-Side Rendering (CSR):

- UI rendered in the browser using JavaScript.
- Pros: Dynamic, fast navigation.
- Cons: Poor initial load SEO (search crawlers may see empty HTML).

Server-Side Rendering (SSR):

- HTML pre-rendered on the server per request.
- Pro: Faster first paint, SEO-friendly.
- Cons: Heavier server load.

Search Engine Optimization (SEO):

- SSR improves SEO by providing crawlable HTML.
- CSR apps may require pre-rendering or dynamic rendering to improve SEO.
