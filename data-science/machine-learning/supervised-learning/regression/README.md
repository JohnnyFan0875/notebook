# Regression

Regression predicts a continuous numeric target such as price, demand, duration, or revenue.

## Topics

- [Linear Regression](linear.md)
- [Ridge Regression](ridge.md)
- [Lasso Regression](lasso.md)
- [Elastic Net Regression](elastic-net.md)
- [Decision Tree Regression](decision-tree.md)

## Notes

- Start with linear regression before moving to regularized models.
- Compare Ridge, Lasso, and Elastic Net when multicollinearity or [feature selection](../../preprocessing/feature-selection.md) matters.
- Use tree-based regression when non-linear patterns are important.

## Beginner Reminders

- Regression is not only about `R^2`; always check the scale and pattern of residuals.
- If the target is highly skewed, think about transformations and robust metrics.
- Start with interpretable baselines before moving to more flexible models.
