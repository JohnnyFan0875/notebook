# Scikit-learn Notes

`scikit-learn` is best treated in this repo as an implementation layer rather than the top-level learning structure.

## Best Fit for scikit-learn

- Predictive modeling
- Pipelines and cross-validation
- Preprocessing for tabular data
- Baseline models and model comparison
