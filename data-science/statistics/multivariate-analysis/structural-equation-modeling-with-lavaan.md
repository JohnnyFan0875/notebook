# 結構方程模型與 lavaan (Structural Equation Modeling, SEM)

SEM 在同一個模型中描述**觀察變數**、**潛在變數**，以及潛在變數之間的關係。它不只是「畫了箭頭的迴歸」：真正的價值在於把**測量模型**與**結構關係**放在同一框架。R 的 `lavaan` 是最常用的套件。

## 何時用

| 情境 | 例子 |
| --- | --- |
| 多個題目測量同一個潛在概念 | 問卷量表、心理測驗 |
| 想**驗證**而非探索因素結構 | 驗證性因素分析 (CFA) |
| 多條關係需要同時評估 | 路徑模型、中介 (mediation) |
| 想明確建模量測誤差 | — |
| 概念有階層 | 高階因素模型 |

| 變數 | 意義 | 圖示慣例 |
| --- | --- | --- |
| 觀察變數 (manifest) | 資料中直接量到的值 | 方形 |
| 潛在變數 (latent) | 由多個指標推論的未觀察構念 | 圓形 / 橢圓 |

> PCA 問「什麼低維結構能解釋變異？」（資料驅動）；SEM 問「**這個假設的**潛在結構及其關係，與資料相符嗎？」（理論驅動）。

## lavaan 語法

| 運算子 | 意義 | 例子 |
| --- | --- | --- |
| `=~` | 潛在變數**由…測量** | `visual =~ x1 + x2 + x3` |
| `~` | 迴歸（結構路徑） | `outcome ~ visual + speed` |
| `~~` | 變異 / 共變異 | `visual ~~ speed` |
| `:=` | 定義衍生參數 | `indirect := a * b`（中介效果） |

```r
library(lavaan)

# 單因素 CFA
fit1 <- cfa("visual =~ x1 + x2 + x3", data = HolzingerSwineford1939)

# 多因素 CFA：要一起配適，才能估計因素之間的相關、檢驗整體結構
model <- '
  visual =~ x1 + x2 + x3
  speed  =~ x7 + x8 + x9
'
fit <- cfa(model, data = HolzingerSwineford1939)
summary(fit, standardized = TRUE, fit.measures = TRUE)   # 看標準化負荷量與配適指標

# 高階因素：多個一階因素由更廣的二階因素解釋
higher <- '
  verbal_comp    =~ v1 + v2 + v3
  working_memory =~ w1 + w2 + w3
  verbal_iq      =~ verbal_comp + working_memory
'

inspect(fit, "cov.lv")    # 潛在變數共變異矩陣（排查 Heywood case）
```

> 分開配適兩個小 CFA ≠ 配適一個聯合多因素模型。聯合模型才能估計潛在因素間的共變異、檢驗完整的驗證性假設。

## 配適指標 (Fit Indices)

| 指標 | 問的問題 | 常用參考 |
| --- | --- | --- |
| CFI / TLI | 比基準模型（變數全不相關）好多少？ | ≥ 0.95 好、≥ 0.90 可接受 |
| RMSEA | 每個自由度還剩多少近似誤差？ | ≤ 0.06 好、≤ 0.08 可接受 |
| SRMR | 觀察與模型隱含相關矩陣的殘差 | ≤ 0.08 |
| χ² 檢定 | 模型完全正確嗎？ | 大樣本幾乎必顯著，不要單獨使用 |

不要只看單一指標當作及格 / 不及格；多個指標與參數估計指向同一方向時，結論才穩。

**標準化負荷量**更好解讀：哪些題目強力代表該構念？有沒有負荷量很弱的題目？構念是否定義不清？

## Heywood Case

| 徵兆 | 常見意義 |
| --- | --- |
| 負的變異數估計 | 某指標行為異常或模型過度擠壓 |
| 相關係數超出 ±1 | 兩個因素在此資料中無法區分 |
| 潛在共變異矩陣非正定 (not positive definite) | 模型設定錯誤、無法識別、指標過度冗餘、樣本不足 |

這種警告**不能忽略**後繼續報告結果。用 `inspect(fit, "cov.lv")` 檢查：潛在相關是否接近 ±1？是否有因素其實是重複的？

## 建議流程

1. 先定義理論上的測量結構
2. 明確寫出 lavaan 語法
3. 用 `cfa()` 或 `sem()` 配適
4. 看整體配適指標
5. 看標準化負荷量與潛在共變異
6. **先處理警告**，再解讀實質結果
7. 確認測量模型可接受後，才討論結構理論是否被支持

| 常見錯誤 | 說明 |
| --- | --- |
| 沒有測量理論就用 SEM | SEM 是驗證工具 |
| 把配適指標當成及格清單 | 它們是證據，不是通關條件 |
| 忽略 Heywood 警告 | 輸出看起來漂亮，但模型不穩 |
| 測量模型還不行就解讀結構路徑 | 順序錯了 |
| 以為軟體估計出來的潛在因素就「真實存在」 | 估計 ≠ 實在 |

> Python 替代：`semopy` 套件語法與 lavaan 相近。
