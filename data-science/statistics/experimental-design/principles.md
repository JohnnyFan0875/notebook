# 實驗設計原則 (Principles of Experimental Design)

Fisher 在 1920 年代提出的三大原則，至今仍是實驗設計的基礎，不是可選的建議，而是得出有效結論的必要條件。

| 原則 | 控制 | 提升 | 一句話 |
| --- | --- | --- | --- |
| **隨機化** (randomization) | 干擾（已知**與未知**） | 內部效度 | 對抗隱藏的偏誤 |
| **重複** (replication) | 隨機誤差 | 檢定力 | 量測雜訊有多大 |
| **區集化** (blocking) | 已知的雜訊變數 | 精確度 | 移除已知的雜訊變異 |
| 局部控制 (local control) | 組內的額外變異 | 精確度 | 標準化流程 |

實務上三者並用：(1) 依已知雜訊變數（醫院、批次）**分區集**；(2) 在每個區集內**隨機**分派處理；(3) 用足夠的**重複**達到檢定力。

## 1. 隨機化 (Randomization)

用隨機機制（而非研究者判斷、方便性或系統規則）分派處理。這是**唯一**能同時控制已知與未知干擾因子的設計策略。

| 沒有隨機化 | 有隨機化 |
| --- | --- |
| 病情較重者可能集中在處理組 | 病情輕重隨機分散到各組 |
| 研究者偏好影響分派 | 偏誤被隨機機制消除 |
| 無法建立因果 | 可推論因果（執行良好時） |

| 隨機抽樣 (random sampling) | 隨機分派 (random assignment) |
| --- | --- |
| 從母體隨機選人 | 把選到的人隨機分到各組 |
| 支持**推廣**（外部效度） | 支持**因果**（內部效度） |

### 隨機化的類型

| 類型 | 做法 | 何時用 |
| --- | --- | --- |
| 簡單隨機化 (simple) | 每個單位獨立分派（像擲硬幣） | 大樣本，平衡會自然出現 |
| 區塊隨機化 (block / permuted block) | 每 4 或 6 人一個區塊，區塊內各組人數相等 | 小樣本、陸續收案；確保各時點組數平衡 |
| 分層隨機化 (stratified) | 先依關鍵變數（年齡、性別）分層，層內再隨機 | 確保各組在重要共變數上平衡 |
| 群集隨機化 (cluster) | 整個群（學校、診所）一起分派 | 個人層級隨機不可行；分析單位要跟著變成群 |

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(42)

# 簡單隨機化：組別人數可能不平衡
simple = rng.choice(["Treatment", "Control"], size=20)

# 區塊隨機化：每 4 人中剛好 2 處理、2 對照
block_assign = np.concatenate([rng.permutation(["T", "T", "C", "C"]) for _ in range(5)])

# 分層隨機化：在每個 (年齡, 性別) 層內做區塊隨機化
df = pd.DataFrame({"age": rng.choice(["<50", "50+"], 100), "sex": rng.choice(["M", "F"], 100)})
df["arm"] = (df.groupby(["age", "sex"])["age"]
               .transform(lambda g: rng.permutation(np.resize(["A", "B"], len(g)))))
pd.crosstab([df["age"], df["sex"]], df["arm"])
```

> **隨機 ≠ 隨便**：交替分派、依病歷號奇偶、依方便性分派都是**系統性**分派，不是隨機。用亂數產生器並記錄 seed。

### 實驗室中的隨機化

| 情境 | 做法 |
| --- | --- |
| 96 孔盤 | 樣本位置隨機排列，避免邊緣效應 (edge effect) 與處理混在一起 |
| 處理順序 | 隨機決定樣本處理 / 上機順序，避免時間漂移與處理混淆 |
| 定序批次 | **每個批次都要包含各組樣本**；絕不能「對照組一批、處理組一批」 |
| 判讀 | 盲化 (blinding)：判讀者不知道樣本屬於哪組 |

## 2. 重複 (Replication)

每個處理組有多個**獨立**實驗單位，才能：

1. 估計實驗誤差（同處理下單位間的自然變異）
2. 把真正的處理效果與隨機雜訊分開
3. 推廣結果

> **重複 ≠ 重複量測**：同一單位量兩次是重複量測（技術重複），不是重複。真正的重複需要獨立的實驗單位（生物重複），見 [核心概念](core-concepts.md#生物實驗中的重複)。

需要幾個重複取決於效果量、變異、α 與目標檢定力，見 [樣本數與檢定力](sample-size-power.md)。經驗值：

| 研究類型 | 每組最少重複 |
| --- | --- |
| 先導 / 篩選 | 3–5 |
| 控制良好的實驗室實驗 | 5–10 |
| RNA-seq 差異表現 | 至少 3，建議 ≥ 6 生物重複 |
| 臨床試驗 | 由正式 power analysis 決定 |
| 網頁 A/B 測試 | 數百到數千（效果量小） |

SE 隨 n 增加而縮小（∝ 1/√n）：n = 3 → 10 → 30 → 100 時，σ = 10 的平均數 SE 約為 5.8 → 3.2 → 1.8 → 1.0。

## 3. 區集化 (Blocking)

把相似的實驗單位分成**區集 (block)**，並讓**每個區集都包含所有處理**，以控制已知的變異來源。

```
沒有區集化：誤差 = 區集效果 + 隨機雜訊 → 誤差被放大，難偵測處理效果
有區集化：  區集效果被模型扣除 → 誤差只剩隨機雜訊，檢定更敏感
```

| 適合區集化 | 不適合 |
| --- | --- |
| 事先能指認雜訊變數 | 沒有有意義的分組變數 |
| 雜訊變數解釋大量變異（經驗上 ≥ 10–15%） | 解釋的變異很少（反而浪費自由度） |
| 天然形成的區集：批次、實驗室、日期、同窩小鼠 | 實驗單位很少 |

```python
# 3 個實驗室（區集效果大）× 2 處理，真實處理效果 = 5
rows = [{"lab": lab, "trt": trt, "y": 100 + b + t + rng.normal(0, 2)}
        for lab, b in {"Lab1": 0, "Lab2": 15, "Lab3": -10}.items()
        for trt, t in {"Control": 0, "Treatment": 5}.items()]
d = pd.DataFrame(rows)

wide = d.pivot(index="lab", columns="trt", values="y")
(wide["Treatment"] - wide["Control"]).mean()      # 區集內差值的平均 ≈ 5

import statsmodels.formula.api as smf
smf.ols("y ~ C(trt) + C(lab)", data=d).fit().params   # 模型中加入區集，效果相同
```

分析時**一定要把區集放進模型**（RCBD ANOVA、配對檢定、混合模型），否則區集化的好處就浪費了。

## 4. 局部控制 (Local Control)

讓組內實驗條件盡可能一致：標準化流程（同設備、同時段、同操作者）、控制環境（溫度、濕度、光照）、訓練並校正人員。

> 隨機化處理**組間**的干擾；局部控制處理**組內**的變異。兩者都需要。

## 事前註冊與分析計畫

在蒐集資料前寫下：主要結果變數、假設、樣本數與 power analysis、分析方法、排除標準。避免事後挑選結果造成的 [p-hacking](../inferential-statistics/hypothesis-testing.md#p-hacking-與提早停止)。臨床試驗在 ClinicalTrials.gov 註冊、一般研究可用 OSF。
