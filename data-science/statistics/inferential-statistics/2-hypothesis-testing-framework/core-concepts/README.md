# Core Concepts of Hypothesis Testing

This section explains the foundational building blocks of statistical inference.

- [Null/Alternative Hypothesis](./null-vs-alternative-hypothesis.md) - define the competing statements tested in statistical inference.
- [Significance Level (α)](./significance-level.md) – sets the acceptable risk of false positives.
- [p-value](./p-value.md) – quantifies evidence against the null hypothesis.
- [t- and z-scores](./t-z-score.md) – standardize differences relative to sampling variability.
- [Type I & II Errors](./type-I-II-error.md) – classify decision errors.
