# Hypothesis Testing Framework

This section builds the conceptual and practical foundation for hypothesis testing — how we decide whether observed data provide enough evidence to reject a null hypothesis (H₀).

## Learning Objectives

- Understand the **core logic** of hypothesis testing.
- Learn how to **set significance levels (α)** and interpret **p-values**.
- Distinguish between **Type I and Type II errors**.
- Check key **assumptions** (normality, independence, variance homogeneity).
- Design valid experiments and studies to ensure reliable inference.
