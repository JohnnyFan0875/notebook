# Descriptive Statistics

**Descriptive statistics** summarize and organize data so that patterns, trends, and relationships can be easily understood. It provides the foundation for all later inferential methods by helping us explore, visualize, and describe data characteristics before drawing conclusions about populations.

Descriptive statistics answer questions like:

- What is the **typical** or **average** value? → _Central tendency_
- How much do values **vary**? → _Variability or spread_
- What is the **shape** of the distribution? → _Symmetry, skewness, kurtosis_
- Are variables **related**? → _Correlation_

## Learning Objectives

- Understand the role of descriptive statistics in the data analysis workflow.
- Compute and interpret measures of **central tendency**, **variability**, **shape**, and **association**.
- Use visualizations to complement numeric summaries.
- Prepare data summaries as a basis for inferential analysis.

## Overview of Topics

| Section                                              | Description                                                                                                                         |
| ---------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| [**Central Tendency**](./central-tendency.md)        | Describes where the center or typical value of the dataset lies — includes mean, median, and mode.                                  |
| [**Variability**](./variability.md)                  | Quantifies how much the data deviate from the center — includes range, variance, standard deviation, and interquartile range (IQR). |
| [**Shape of Distribution**](./shape-distribution.md) | Describes the form of the distribution, such as skewness, kurtosis, and symmetry; introduces basic normality concepts.              |
| [**Correlation**](./correlation.md)                  | Measures the strength and direction of the relationship between two variables (Pearson, Spearman, Kendall, and autocorrelation).    |

## Visualization and Exploration

Descriptive statistics combine **numerical summaries** with **graphical exploration**:

| Visualization    | Purpose                                      |
| ---------------- | -------------------------------------------- |
| **Histogram**    | Shows distribution and shape.                |
| **Boxplot**      | Displays median, IQR, and outliers.          |
| **Scatter plot** | Illustrates relationships between variables. |
| **Q–Q plot**     | Assesses normality visually.                 |

These tools provide essential context before hypothesis testing or model fitting.

## Relationship to Inferential Statistics

Descriptive analysis focuses on **summarizing observed data**, while inferential statistics generalize from samples to populations. Together, they form the foundation of statistical reasoning:

| Type            | Goal                               | Example                                                                  |
| --------------- | ---------------------------------- | ------------------------------------------------------------------------ |
| **Descriptive** | Summarize what is observed         | "The average height is 170 cm with SD = 6."                              |
| **Inferential** | Draw conclusions beyond the sample | "We are 95% confident that the population mean lies between 168–172 cm." |

Understanding descriptive statistics ensures accurate interpretation and reliable inference.

## Key Takeaways

- Descriptive statistics organize and summarize raw data into meaningful information.
- Central tendency, variability, and shape together describe a distribution’s full characteristics.
- Correlation extends description to the relationships among variables.
- Always complement descriptive measures with visualization for intuitive understanding.
