# 存活分析結果解讀 (Interpretation)

依建構分析的順序解讀：**描述**（KM 曲線）→ **比較**（log-rank）→ **建模**（Cox HR）。三層互補、缺一不可。先理解原始存活型態，模型摘要才不會被誤讀。統計顯著還要搭配臨床 / 生物合理性才有意義。

## 各輸出怎麼讀

| 輸出 | 意義 | 例句 |
| --- | --- | --- |
| KM 曲線上的點 Ŝ(t) | 存活**超過** t 的機率 | 「12 個月存活率為 70%」 |
| 曲線陡峭程度 | 事件發生速率 | 陡 = 事件率高 |
| 中位存活時間 | Ŝ(t) = 0.5 的時間 | 「處理組 18 個月、對照組 12 個月」 |
| RMST(τ) | 到 τ 為止的平均無事件時間 | 「3 年內平均多 4.2 個月無復發」 |
| Log-rank p | 存活分配是否不同 | 「log-rank p = 0.02」 |
| HR = e^β | 瞬間事件速率的相對倍數 | 見下 |

| HR | 解讀 |
| --- | --- |
| = 1 | 風險無差異 |
| > 1 | 風險較高 → 存活較短 |
| < 1 | 風險較低 → 存活較長；「降低 35%」= HR 0.65 |

例句：

- 「帶有突變 X 的病人死亡風險為 1.8 倍（HR = 1.8，95% CI 1.2–2.7，p = 0.004）。」
- 「治療 A 使疾病惡化的風險降低 35%（HR = 0.65，95% CI 0.50–0.85）。」

HR 的 95% CI **不包含 1** → 統計顯著；CI 越窄越精確。HR 不是機率比值，見 [Cox 模型](cox-ph-model.md#解讀-hazard-ratio)。

## 絕對差異 vs 相對差異

最常見的解讀錯誤是**只報 HR**。

| 類型 | 問題 | 指標 |
| --- | --- | --- |
| **絕對** | 一組比另一組多幾個月無事件？某時點存活率差多少？ | 中位數差、固定時點存活率差、RMST 差 |
| **相對** | 瞬間事件速率高 / 低多少？ | HR |

同樣 HR = 0.7，在基線風險高的族群與基線風險低的族群，絕對效益差很多。完整的報告兩者都包含。

> 「雖然 HR 統計顯著，但 3 年存活率的絕對差異只有 4%，臨床影響可能有限。」

## 報告前要確認

| 項目 | 檢查 |
| --- | --- |
| 比例風險假設 | Schoenfeld 殘差 / log-log 圖；違反時考慮分層或時間相依係數，見 [模型診斷](diagnostics.md) |
| 連續共變數線性 | Martingale 殘差或樣條 |
| 尾端風險集 | 尾端人數很少時估計不穩，不要過度解讀 |
| 設限 | 設限 ≠ 無事件存活；被設限的人之後仍可能發生事件 |
| 多重檢定 | 多基因 / 多變數分析時要校正（如 FDR），見 [多重檢定校正](../inferential-statistics/multiple-testing.md) |
| 一致性 | 子群體與外部世代中結果是否一致 |
| 依資料決定的切點 | 用「最佳切點」把連續變數（如基因表現）分高 / 低組會嚴重高估效果與顯著性；優先用連續變數或事先指定的切點（中位數、臨床門檻） |

## 報告範本

1. 描述觀察到的存活型態或中位存活時間
2. 組間比較結果與 log-rank p 值
3. Cox 估計：HR、95% CI、調整了哪些共變數
4. 主要假設是否檢查過
5. 結尾說明效果的實務 / 臨床意義（最好附絕對差異）

```text
Kaplan-Meier 分析顯示，接受藥物 A 的病人存活顯著較長（中位存活 24 vs 15 個月；log-rank p = 0.02）。
調整年齡與分期後，Cox 模型確認此結果（HR = 0.60，95% CI 0.42–0.86），
Schoenfeld 檢定未顯示違反比例風險假設（p = 0.72）。
3 年存活率分別為 41% 與 28%（絕對差異 13%），顯示藥物 A 具臨床上有意義的存活效益。
```

> 解讀時把問題轉回**時間**：典型的無事件時間是多久？到某個有意義的時間點，一組多了多少無事件時間？主要故事是關於時機、瞬間風險，還是累積機率？HR 很少是故事的全部。
