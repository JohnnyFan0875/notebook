# Corporate Finance

這個模組整理的是公司如何做投資決策、如何籌資，以及賺到的現金最後如何回到股東手上。和 trading 或 time series 不同，corporate finance 關心的不是市場短線波動，而是公司層級的資本配置。

Key point: corporate finance 的很多公式看起來像單純計算題，但背後其實都在回答同一件事: 這筆資本應不應該投入、由誰出、以及最後如何回收。

- [Budgeting and Financial Ratio Monitoring](budgeting-and-financial-ratio-monitoring.md): budget / forecast / actual、KPI、liquidity ratios、actual vs. budget review 與 finance dashboard signals
- [Capital Budgeting](capital-budgeting.md): present value、payback、NPV、IRR、XNPV、XIRR、profitability index 與專案排序
- [Capital Structure and Funding](capital-structure-and-funding.md): enterprise value、equity value、capital stack、debt / equity tradeoff、debt capacity 與 WACC
- [Business Valuation](business-valuation.md): DCF、terminal value、relative valuation、comps、precedent transactions 與 football field chart
- [Equity Valuation Models](equity-valuation-models.md): FCFE、DDM、cost of equity、beta、perpetuity growth checks 與 equity-specific implied price logic
- [Capital Return and Payout](capital-return-and-payout.md): retained earnings、dividends、share buybacks 與資本返還的判斷框架

## Reading Order

1. 先看 [Financial Modeling Workflows](financial-modeling-workflows.md)，建立 assumptions、inputs、outputs 與 scenario analysis 的建模習慣。
2. 再看 [Financial Statements for Forecasting](financial-statements-for-forecasting.md)，把 income statement、balance sheet、cash flow 與 fiscal periods 放回 forecast 脈絡。
3. 再看 [Budgeting and Financial Ratio Monitoring](budgeting-and-financial-ratio-monitoring.md)，把 budget / forecast / actual 與 KPI 監控接回日常管理節奏。
4. 再看 [Capital Budgeting](capital-budgeting.md)，理解資金投進去之前要怎麼評估。
5. 再看 [Capital Structure and Funding](capital-structure-and-funding.md)，理解資金究竟由誰提供、成本是多少。
6. 接著看 [Business Valuation](business-valuation.md)，把現金流、WACC、multiple 與市場比較收斂成估值框架。
7. 再看 [Equity Valuation Models](equity-valuation-models.md)，把 FCFE、DDM、beta 與 cost of equity 放回股東視角。
8. 最後看 [Capital Return and Payout](capital-return-and-payout.md)，理解公司成熟後如何把資本回到投資人手上。
