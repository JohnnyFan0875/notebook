# 應用領域 (Applied Domains)

把統計、ML 與最佳化方法放進特定領域的情境。每個領域只保留可遷移的方法；通用理論留在 [Statistics](../statistics/README.md) 與 [Machine Learning](../machine-learning/README.md)。

| 領域 | 內容 | 可遷移的方法 |
| --- | --- | --- |
| [Finance](finance/README.md) | 報酬率、自相關、投資組合、風險、信用風險、回測、保險年金 | 時間序列、蒙地卡羅模擬、VaR、分類模型評估、生存分析 |
| [Marketing Analytics](marketing-analytics/README.md) | market response、choice model、campaign measurement | GLM、多項 logit、uplift 與 A/B 測試 |
| [Operations Research](operations-research/README.md) | 線性 / 整數規劃、供應鏈最佳化 | 決策變數、目標函數、約束、敏感度分析 |
| [Process Analytics](process-analytics/README.md) | event log、trace、process variant、throughput | 事件序列分析、等待時間分布（如醫療流程） |

> 選讀章節：依工作需要再挑一個領域讀，不必依序。
