# 交易策略與回測 (Trading Strategies and Backtesting)

投資組合分析問「一組資產的配置是否合理」；交易策略問「什麼時候進出場，規則長期跑起來會怎樣」。好的交易研究先把整條鏈定義清楚，而不是先追求漂亮的報酬曲線：

```
資料 → 指標 (indicator) → 訊號 (signal) → 部位 (position) → 回測 → 基準比較 → 風險檢視
```

回測紀律（look-ahead bias、過擬合、樣本外驗證、多重比較）是這篇最可遷移的部分：同樣的錯誤也出現在任何從歷史資料挑規則的研究中。

## 交易 vs 投資

| | 交易 | 投資 |
| --- | --- | --- |
| 持有期 | 短 | 長 |
| 關注 | 短中期趨勢、反轉、波動 | 基本面、現金流、企業品質 |
| 方向 | 常可做多也可做空 | 多半只做多 |
| 影響 | 資料頻率、可容忍的周轉率、該看的基準與風險指標 | |

| 邏輯 | 假設 | 例子 |
| --- | --- | --- |
| 趨勢追蹤 / 動能 (divergence) | 目前的方向會延續 | 均線、突破 |
| 均值回歸 (convergence) | 偏離終究會回來 | RSI、布林通道、配對交易 |

## 指標是市場資料的特徵工程

技術指標不是預言機，而是把歷史價格、成交量、波動轉成較容易觀察的訊號：這個指標在摘要什麼資訊？對哪種市場狀態敏感？和決策規則是什麼關係？不同頻率下的型態可能完全不同：日資料上的訊號不能直接搬到週資料或小時資料。

| 類型 | 例子 | 用途 |
| --- | --- | --- |
| 趨勢 | 簡單 / 指數移動平均（SMA、EMA） | 方向與強度；有落後、盤整時反覆被洗 (whipsaw) |
| 動能 / 擺盪 | RSI：> 70 偏熱、< 30 偏冷 | 常當成均值回歸的進場時機過濾，而不是單獨決定方向 |
| 波動 | 布林通道（均線 ± k 倍標準差）、ATR | 價格偏離程度 |

組合訊號常比單一指標穩：用長週期均線定義大方向（regime filter，例如只在 SMA50 > SMA200 時做多），再用短週期擺盪指標找進場時機（entry timing）。

```python
import pandas as pd
import numpy as np

px = prices["adj_close"]                                # 用調整後價格（股利與分割）
sma50, sma200 = px.rolling(50).mean(), px.rolling(200).mean()

delta = px.diff()
gain = delta.clip(lower=0).ewm(alpha=1/14, adjust=False).mean()
loss = (-delta.clip(upper=0)).ewm(alpha=1/14, adjust=False).mean()
rsi = 100 - 100 / (1 + gain / loss)                     # Wilder 平滑的 14 日 RSI

signal = ((sma50 > sma200) & (rsi < 30)).astype(int)    # 多頭環境中的超賣 → 做多
position = signal.shift(1).fillna(0)                    # 關鍵：今天的訊號明天才能交易
ret = px.pct_change().fillna(0)
cost = 0.001 * position.diff().abs().fillna(0)          # 每次換手的交易成本（10 bp）
strat = position * ret - cost
bench = ret                                             # buy-and-hold
```

> `shift(1)` 是回測最重要的一行：用收盤價算出的訊號，最快只能在下一根 K 棒執行。忘了它，就是用未來資訊交易 (look-ahead bias)，績效會漂亮得不真實。

## 訊號不等於策略

同一個 `price > SMA` 訊號可以對應全倉持有 / 空手、持有 50% / 轉現金、做多 / 反手做空等不同策略。從訊號到策略還要定義：

| 層 | 內容 |
| --- | --- |
| Indicator | 從資料算出的特徵 |
| Signal | 根據條件判斷該不該動作 |
| Rule | 怎麼下單、加碼、減碼、出場、取消掛單；目標部位或權重、再平衡頻率、能否做空、與其他風控條件的連動 |

真正的複雜度通常藏在執行邏輯。

| 工具 | 用途 |
| --- | --- |
| Python `bt` | `SelectWhere()` 依訊號選資產、`WeighTarget()` 把訊號轉成權重、`Backtest()` / `run()` 執行 |
| Python `vectorbt`、`backtrader` | 向量化 / 事件驅動回測 |
| R `quantmod` | 取得與瀏覽金融時間序列（`getSymbols()`） |
| R `TTR` | 技術指標（`SMA()`、`RSI()`） |
| R `quantstrat` | 把 indicator、signal、rule 串成交易系統 |

## 基準

沒有基準，很多策略看起來都比實際有說服力。

| 基準 | 回答 |
| --- | --- |
| 同一資產的 buy-and-hold | 主動規則是否真的有額外價值？ |
| 大盤指數（S&P 500） | 是否勝過市場？ |
| 參數更少的簡單策略 | 複雜度是否值得？ |

只比基準多一點報酬，卻換來更深的回撤、更多周轉、更差的穩定性，通常不值得。

## 回測後要看什麼

| 面向 | 指標 |
| --- | --- |
| 賺多少 | 總報酬、CAGR、日 / 月 / 年平均報酬 |
| 波動多大 | 日 / 月 / 年波動、Sharpe、Sortino |
| 最痛多深 | 最大回撤、平均回撤 |
| 壞時期多久 | 回撤持續天數、回復時間 |
| 極端 | 最好 / 最差的日、月、年 |
| 交易層級 | 勝率 (percent positive)、平均賺賠比、獲利 / 回撤比、周轉率 |

投資人常不是死在單日波動，而是死在長時間回不來。指標定義見 [投資組合與風險](portfolio-and-risk.md#風險調整後報酬)。

| 系統 | 勝率 | 平均賺賠比 | 失敗方式 |
| --- | --- | --- | --- |
| 趨勢追蹤 | 常不高 | 較高 | 靠少數大行情拉起整體績效；盤整期間持續小虧 |
| 均值回歸 | 常較高 | 較低 | 多數時候小賺，遇到單邊趨勢時大傷 |

低勝率不一定是壞策略，高勝率也不代表尾部風險可接受：要連同報酬形狀一起看。

### 先看圖

第一輪檢視先看價格與指標疊圖、訊號 / 部位時間線、累積損益、回撤路徑（R 的 `chart.Posn()`、`add_TA()`）。很多回測錯誤不是統計問題，而是欄位用錯、訊號偏移一根 K 棒、規則沒照想像執行；這些看圖比看摘要表更早發現。

## 參數最佳化與過擬合

SMA 20、50、100 哪個好？逐一回測再挑歷史最好的一組，很容易只是把雜訊當成規律。

| 健康做法 | 理由 |
| --- | --- |
| 先用領域直覺縮小參數範圍 | 減少嘗試次數 |
| 減少自由參數 | 每多一個參數就多一個過擬合的機會 |
| 把最佳化當成敏感度分析 | 好策略在參數附近應該平穩，而不是只有一個尖峰 |
| 保留樣本外期間、做 walk-forward | 在訓練窗選參數 → 在下一段測試 → 往前滾動 |
| 計入嘗試過的策略數 | 試了 100 組參數，最好那組的 Sharpe 必然被高估；用 deflated Sharpe ratio 或多重比較校正，見 [多重檢定](../../statistics/inferential-statistics/multiple-testing.md) |

這和 ML 的資料洩漏、超參數調整後在測試集報告分數是同一類問題，見 [資料洩漏](../../machine-learning/foundations/data-leakage.md)、[交叉驗證](../../machine-learning/workflow/cross-validation.md)（時間序列要用前向切分）。

## 常見錯誤

| 錯誤 | 後果 |
| --- | --- |
| 訊號沒有延後一期 | look-ahead bias |
| 用原始收盤價算長期報酬 | 除息與分割造成假的漲跌 |
| 只用現存股票回測 | 存活者偏差 |
| 只看樣本內最佳參數 | 過擬合 |
| 不和基準比、只報絕對報酬 | 高估價值 |
| 忽略交易成本、滑價、流動性 | 高周轉策略在現實中虧損 |
| 把指標當因果解釋 | 它只是歷史模式摘要 |
| 不同頻率、不同市場狀態直接套用同一組規則 | 規則失效 |

很多「看起來有效」的策略問題不在數學，而在研究設計太寬鬆。
