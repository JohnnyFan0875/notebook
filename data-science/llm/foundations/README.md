# Foundations

This module covers the core ideas behind large language models before they are turned into tools, agents, or products.

Key point: If you only learn prompts and APIs, it is easy to overestimate what an LLM understands. Foundations matter because they explain what the model is actually doing, where its capabilities come from, and why its failures are predictable.
