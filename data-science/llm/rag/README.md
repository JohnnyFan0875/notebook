# RAG

Retrieval-augmented generation (RAG) combines a language model with a retrieval step so the answer can use external knowledge instead of relying only on model parameters.

## Suggested Reading Order

| Note | Focus |
| --- | --- |
| [Embeddings and Semantic Search](embeddings-and-semantic-search.md) | what embeddings represent, semantic search, recommendations, zero-shot classification |
| [Vector Databases for RAG](vector-databases.md) | indexes, metadata, querying, namespaces, batching |
| [RAG Pipeline](rag-pipeline.md) | end-to-end flow: loading, chunking, retriever setup, prompt grounding, vector-RAG limitations, production checklist |

Tip: Chunking and prompt grounding usually matter more than the choice of vector store.
