# Human Protein Atlas (HPA)

瑞典 SciLifeLab 自 2003 年起的計畫，結合抗體染色、RNA-seq 與質譜，描繪人類蛋白在組織、細胞類型、胞器的表現與定位。資料全部開放。

| 項目 | 內容 |
| --- | --- |
| 入口 | [proteinatlas.org](https://www.proteinatlas.org/)（版本見 Release History） |
| 資料類型 | 免疫組織化學 (IHC)、免疫螢光、bulk / 單細胞 / 單核 RNA-seq、質譜、血液蛋白（Olink、SomaScan） |
| 授權 | CC BY 4.0（部分第三方資料另有條款，見官網 Licence & Citation） |
| 替代 / 互補 | [GTEx](../../genetics/databases/functional-expression/gtex.md)（組織 RNA + eQTL）、CELLxGENE（單細胞）、PaxDb（蛋白豐度） |

## 九個資源

| 資源 | 回答的問題 |
| --- | --- |
| Tissue | 蛋白 / mRNA 在各正常組織的表現（組織專一性分類） |
| Brain | 人、豬、小鼠腦區的表現 |
| Single Cell | 哪些細胞類型表現（含免疫細胞、腦單核資料） |
| Subcellular | 蛋白在細胞內哪個胞器 |
| Cancer | 各癌別的表現與病人存活關聯（預後基因） |
| Blood | 血漿濃度、各疾病的血液蛋白變化 |
| Cell Line | 1,200 多種細胞株的 RNA 表現 |
| Structure | 預測 3D 結構（含 AlphaFold） |
| Interaction | 蛋白交互作用與代謝網絡 |

> IHC 結果取決於抗體品質：先看該抗體的可靠度評分 (reliability score) 與是否與 RNA 結果一致，再下結論。癌症的存活分析屬於探索性關聯，不等於可用的預後標記。
