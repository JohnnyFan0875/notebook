# 分子生物學 (Molecular Biology)

濕實驗室 (wet lab) 偵測核酸與蛋白質的基本方法，以及蛋白質層級的參考資料庫。生資分析的結果（差異表現、變異、標記）最後常要回到這些方法驗證，而資料庫則提供基因 / 變異的蛋白質功能背景。

| 模組 | 內容 | 回答的問題 |
| --- | --- | --- |
| [實驗方法](experimental-methods/README.md) | 電泳、Southern / Northern / Western blot、qPCR、ELISA、寡核苷酸合成、病毒檢測、BAC | 要偵測 DNA、RNA 還是蛋白質？要定性還是定量？用哪個方法驗證 NGS 結果？ |
| [分子資料庫](molecular-databases/README.md) | UniProt、InterPro、Human Protein Atlas、Protein of the Month | 這個蛋白質有什麼功能與結構域？在哪個組織 / 細胞表現？ |
