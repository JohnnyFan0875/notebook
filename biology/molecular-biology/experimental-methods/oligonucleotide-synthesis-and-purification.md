# 寡核苷酸合成與純化 (Oligonucleotide Synthesis & Purification)

引子、探針、NGS adapter 都是化學合成的寡核苷酸 (oligo)。合成產物混有大量短鏈與鹽類，訂購時要依用途選擇純化等級：選太低會影響實驗，選太高則多花錢與時間。

## 固相合成 (Phosphoramidite Method)

在 DNA 合成儀上，以固定在固相載體 (CPG) 上的第一個核苷酸為 3' 端，**由 3' 往 5' 方向**逐一接上受保護的核苷酸：

```text
脫 DMT（去 5' 保護基）→ 偶合 (coupling) 下一個 phosphoramidite
→ capping（封住未反應的鏈，讓它停止延長）→ 氧化 → 重複
合成結束 → 氨解：從載體切下並脫去鹼基與磷酸保護基
```

| 保護基 | 位置 |
| --- | --- |
| DMT（二甲氧基三苯甲基） | 5'-OH；最後一輪可保留（DMT-on）供純化用 |
| 苯甲醯基 (benzoyl) | A、C 的鹼基 |
| 異丁醯基 (isobutyryl) | G 的鹼基 |
| 氰乙基 (cyanoethyl) | 磷酸 |
| 無 | T 不需保護 |

### 為什麼一定要純化

每次偶合效率即使有 97–99%，累積下來全長產物比例仍快速下降：

| 長度 | 每步 98.5% | 每步 97.5% |
| --- | --- | --- |
| 20 nt | 0.985¹⁹ ≈ 75% | 0.975¹⁹ ≈ 62% |
| 50 nt | 0.985⁴⁹ ≈ 48% | 0.975⁴⁹ ≈ 29% |
| 100 nt | 0.985⁹⁹ ≈ 22% | 0.975⁹⁹ ≈ 8% |

（n nt 需要 n − 1 次偶合。）粗產物的雜質包括：

- **截短產物 (n−1、n−2…)**：最難去除，會造成定量不準、選殖出現缺失突變、定序錯誤。
- **鹽與保護基殘留**：苯甲酸銨、異丁酸銨、丙烯腈等，影響吸光定量並抑制酵素反應。

## 純化等級比較

| 方法 | 原理 | 去除截短產物 | 長度限制 | 適用 |
| --- | --- | --- | --- | --- |
| 脫鹽 (desalting) | 酒精沉澱、分子篩或反相管柱去除小分子 | ✗ | 無 | 一般 PCR、< 35 nt 的定序引子；多數廠商的預設 |
| 管柱純化（OPC / RPC cartridge） | DMT-on 全長鏈較疏水，吸附在反相管柱上，無 DMT 的截短鏈被洗掉 | 部分 | 約 < 40–50 nt | 要求較高的 PCR；仍常混有 n−1、n−2 |
| HPLC（反相 RP-HPLC / 離子交換 IE-HPLC） | RP：同樣依 DMT 疏水性；IE：依電荷（長度） | 好 | RP 約 < 40–50 nt | qPCR 探針、螢光 / 修飾 oligo（修飾基團改變疏水性，HPLC 最適合）|
| PAGE | 變性聚丙烯醯胺膠依長度分離，可分辨 1 nt 差異 | 最好 | 幾乎無（可達 100+ nt） | 選殖、定點突變、基因合成、長 oligo、NGS adapter |

| 方法 | 缺點 |
| --- | --- |
| 脫鹽（酒精沉澱） | 短 oligo 回收率低 |
| RP 管柱 / HPLC | 長度增加後全長與截短鏈的疏水性差異變小，解析度下降；G 多的序列易形成二級結構 |
| PAGE | 費時、產量低（回收率常 < 50%）、價格高；會破壞部分螢光修飾 |

> 實務選擇：引子長度 ≤ 35 nt 做一般 PCR → 脫鹽；qPCR TaqMan 探針、修飾 oligo → HPLC；選殖 / 突變 / 長 oligo → PAGE 或 PAGE + HPLC 雙重純化。設計規則見[引子設計](../../bioinformatics-tools/primer-design/README.md)。
