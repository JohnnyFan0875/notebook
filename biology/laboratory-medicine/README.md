# 檢驗醫學 (Laboratory Medicine)

臨床檢驗從採檢到發報告的實務知識：檢體類型與前處理、血庫輸血檢驗、試劑與化學品的安全與品質文件。分析前 (pre-analytical) 的變因是檢驗誤差最主要的來源，也直接影響研究用檢體（cfDNA、PBMC、蛋白質體）的資料品質。

| 模組 | 內容 | 回答的問題 |
| --- | --- | --- |
| [檢體類型](sample-types/README.md) | 血清 vs 血漿、採血管與添加劑、分析前變因 | 這個檢驗要用哪種管子？溶血、放太久會影響什麼？ |
| [血庫與輸血](blood-bank-and-transfusion/README.md) | ABO / RhD 血型、抗體篩檢、交叉試驗、血液成分、輸血反應 | 輸血前要做哪些檢驗？各血品怎麼保存、何時用？ |
| [物質安全與品質](material-safety-and-quality/README.md) | SDS（物質安全資料表）、COA（分析證明書） | 這個試劑有什麼危害？這批試劑是否符合規格？ |

相關：檢驗結果的代碼標準見 [LOINC](../clinical-informatics-and-standards/clinical-terminology/loinc.md)；檢驗方法的確效見 [檢驗驗證與確效](../genomics/assay-validation/README.md)。
