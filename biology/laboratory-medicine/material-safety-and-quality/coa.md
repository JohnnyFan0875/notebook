# 分析證明書 (Certificate of Analysis, COA)

COA 是製造商針對**特定批號**出具的品管檢驗結果，證明該批試劑、標準品或材料符合規格。同一產品不同批號的 COA 不同，所以它是批號追溯與批次差異排查的依據。

## 常見欄位

| 欄位 | 內容 | 例 |
| --- | --- | --- |
| 產品資訊 | 名稱、型號 (catalog number) | — |
| 批號 (lot / batch) | 這份證明對應的批次 | 與試劑瓶上的批號核對 |
| 檢驗項目 | 測了哪些品質屬性 | 純度、濃度、活性、pH、內毒素、無菌、核酸酶殘留 |
| 規格 (specification) | 每個項目的允收標準 | 純度 ≥ 99%、A260/A280 1.8–2.0 |
| 結果 | 這一批的實測值 | 純度 99.6% |
| 判定 | 合格 / 不合格 | Pass |
| 日期 | 製造日、效期或再驗日 (retest date) | — |
| 簽核 | 品保人員簽名 | — |

## 用途

| 情境 | 做法 |
| --- | --- |
| 進貨驗收 | 核對批號、效期、結果是否在規格內 |
| 品質文件與追溯 | 歸檔供 ISO 15189 / ISO 17025 稽核；結果異常時追查是否同一批 |
| 標準品 / 品管物質 | 確認認證值與不確定度（可追溯的參考物質還會有 certificate of reference material） |
| 批次效應排查 | 換新批號後結果飄移時，比較新舊批 COA，必要時做新舊批平行比對 (lot-to-lot verification) |

> COA 證明的是製造商在出廠時的檢驗結果，不代表運送與保存後仍符合；臨床檢驗換新批號時仍需依規定做批號間驗證，見 [檢驗驗證與確效](../../genomics/assay-validation/README.md)。
