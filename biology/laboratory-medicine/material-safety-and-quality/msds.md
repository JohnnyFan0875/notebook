# 安全資料表 (SDS / MSDS)

安全資料表 (Safety Data Sheet, SDS) 描述化學品的危害、安全處理、儲存與緊急應變資訊。舊稱物質安全資料表 (Material Safety Data Sheet, MSDS)；依聯合國全球調和制度 (GHS) 統一為 16 節格式後，多數國家改稱 SDS（台灣法規名稱仍常見「安全資料表」）。

## 16 節內容

| 節 | 內容 | 實驗室最常查 |
| --- | --- | --- |
| 1 | 物品與廠商資料 | 緊急聯絡電話 |
| 2 | 危害辨識（GHS 分類、象徵符號、警示語、危害 / 防範說明） | ✔ 先看這節 |
| 3 | 成分辨識 | 濃度、CAS 號碼 |
| 4 | 急救措施 | ✔ 皮膚 / 眼睛接觸、吸入、誤食 |
| 5 | 滅火措施 | |
| 6 | 洩漏處理 | ✔ 溢出時怎麼清 |
| 7 | 安全處置與儲存 | ✔ 溫度、相容性、是否需通風櫃 |
| 8 | 暴露控制 / 個人防護 | ✔ 手套材質、護目鏡、呼吸防護、容許濃度 |
| 9 | 物理及化學性質 | 閃火點、沸點、溶解度 |
| 10 | 安定性及反應性 | ✔ 不相容物質（避免混放） |
| 11 | 毒性資料 | LD50、致癌性 |
| 12 | 生態資料 | |
| 13 | 廢棄處置 | ✔ 廢液分類 |
| 14 | 運送資料 | 聯合國編號、運輸分類 |
| 15 | 法規資料 | 各國管制清單 |
| 16 | 其他資料 | 修訂日期 |

## GHS 象徵符號

| 符號 | 意義 | 實驗室常見例 |
| --- | --- | --- |
| 骷髏與交叉骨 | 急毒性 | 疊氮化鈉、氰化物 |
| 健康危害（人形） | 致癌、致突變、生殖毒性、呼吸道致敏 | 甲醛、丙烯醯胺、氯仿 |
| 腐蝕 | 皮膚腐蝕、嚴重眼損傷、金屬腐蝕 | 濃酸、濃鹼、酚 |
| 火焰 | 易燃 | 乙醇、異丙醇、二甲苯 |
| 驚嘆號 | 刺激、致敏、輕度急毒性 | 多數緩衝液添加物 |
| 環境 | 水生毒性 | 重金屬鹽類 |

> 核酸染劑（如 ethidium bromide）、TRIzol（含酚與異硫氰酸胍）、甲醛固定液是生物實驗室最常見的高危害試劑；TRIzol 不可與漂白水混用（產生有毒氣體），這類不相容資訊在第 10 節。

## 注意

| 重點 | 說明 |
| --- | --- |
| 版本 | 確認是最新修訂版（第 16 節日期），供應商更新配方時 SDS 會改 |
| 在地規範 | SDS 是一般性資訊，要搭配單位的化學品管理與廢棄物規範 |
| 混合物 | 自配溶液的危害以最危險的成分為準 |
| 生物性危害 | 感染性物質的風險依生物安全等級 (BSL) 管理，不在 SDS 範圍 |
