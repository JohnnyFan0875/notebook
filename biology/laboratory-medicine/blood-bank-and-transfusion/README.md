# 血庫與輸血 (Blood Bank and Transfusion)

血庫檢驗的目的是讓輸入的血品與受血者相容、不引發溶血或其他輸血反應。核心流程是「血型 → 抗體篩檢 → 交叉試驗 → 發血」，再加上血品的製備、保存與特殊處理。

參考簡報：[臨床血庫檢驗介紹（Scribd）](https://www.scribd.com/document/771843385/%E8%87%A8%E5%BA%8A%E8%A1%80%E5%BA%AB%E6%AA%A2%E9%A9%97%E4%BB%8B%E7%B4%B9)

## 輸血前檢驗流程

```
受血者檢體（EDTA 全血）
  ├─ ABO 正向 + 反向定型、RhD 定型
  ├─ 不規則抗體篩檢（IAT）──陽性──► 抗體鑑定 → 選抗原陰性血品
  └─ 交叉試驗（受血者血清 × 供血者紅血球）
        └─ 相容 ──► 發血 ──► 輸血中監測反應
```

## 血型定型

| 檢驗 | 做法 | 看什麼 |
| --- | --- | --- |
| 正向定型 (forward typing) | 受血者紅血球 + anti-A、anti-B 試劑 | 紅血球上有哪些抗原 |
| 反向定型 (reverse typing) | 受血者血清 + A₁、B 型試劑紅血球 | 血清中有哪些天然抗體 |
| RhD 定型 | 紅血球 + anti-D | D 抗原有無；弱 D (weak D)、部分 D (partial D) 需進一步判讀 |

| ABO 血型 | 紅血球抗原 | 血清抗體 | 可接受的紅血球 | 可接受的血漿 |
| --- | --- | --- | --- | --- |
| O | 無 | anti-A、anti-B | O | O、A、B、AB |
| A | A | anti-B | A、O | A、AB |
| B | B | anti-A | B、O | B、AB |
| AB | A、B | 無 | AB、A、B、O | AB |

> 紅血球看「受血者的抗體會不會打供血者的抗原」，血漿反過來看「供血者的抗體會不會打受血者的紅血球」，所以 O 型是紅血球的萬用供血者、AB 型是血漿的萬用供血者。

| 正反定型不一致的常見原因 | 說明 |
| --- | --- |
| 新生兒 | 4 個月內尚未產生自己的 ABO 抗體，只做正向定型 |
| 高齡、免疫低下、低丙種球蛋白 | 反向定型抗體弱或缺 |
| 亞型（A₂、A<sub>x</sub>、B<sub>3</sub>…） | 抗原弱，正向反應弱 |
| 冷凝集素、Rouleaux | 非專一凝集造成假陽性 |
| 近期輸血、骨髓移植 | 混合視野 (mixed field) |
| Bombay 表型 (O<sub>h</sub>) | 缺 H 抗原，血清有 anti-H，只能輸 Bombay 血 |

> RhD 陰性在台灣與東亞族群比例遠低於歐洲族群，RhD 陰性血品需要特別調度。

## 抗體檢驗

| 檢驗 | 偵測 | 用途 |
| --- | --- | --- |
| 間接抗球蛋白試驗 (IAT) | 血清中**游離**的抗紅血球抗體 | 抗體篩檢、抗體鑑定、交叉試驗 |
| 直接抗球蛋白試驗 (DAT，直接 Coombs) | **已附著**在紅血球上的抗體 / 補體 | 自體免疫溶血、新生兒溶血病、溶血性輸血反應 |
| 抗體篩檢 (antibody screen) | 用 2–3 支已知抗原的篩檢細胞做 IAT | 判斷有無臨床意義的不規則抗體 |
| 抗體鑑定 (panel) | 用 10 支以上已知抗原組合的細胞 | 篩檢陽性時找出是哪個抗體（anti-E、anti-Jk<sup>a</sup>…） |

> 台灣人 Mi<sup>a</sup>（MNS 系統）抗原的比例比歐美族群高得多，anti-Mi<sup>a</sup> 可造成溶血性輸血反應，因此本地的篩檢細胞需包含 Mi(a+) 細胞。

## 交叉試驗 (Crossmatch)

| 類型 | 做法 | 適用 |
| --- | --- | --- |
| 主要交叉試驗 (major) | 受血者血清 + 供血者紅血球 | 標準 |
| 立即離心 (immediate spin) | 室溫離心看凝集，主要確認 ABO 相容 | 抗體篩檢陰性時 |
| 抗球蛋白交叉 (AHG) | 加 37 °C 培養與抗球蛋白試劑 | 抗體篩檢陽性或有抗體病史 |
| 電子交叉 (electronic) | 資訊系統比對血型，不做實際試驗 | 兩次獨立血型一致、篩檢陰性、系統經確效 |

## 血液成分 (Blood Components)

| 血品 | 內容 | 保存 | 主要適應 |
| --- | --- | --- | --- |
| 濃縮紅血球 (packed RBC) | 紅血球 | 1–6 °C；CPDA-1 約 35 天、添加保存液（SAGM 等）約 42 天 | 貧血、急性失血 |
| 血小板（分離術 / 多袋混合） | 血小板 | 20–24 °C 持續搖動，效期短（約 5 天） | 血小板低下且出血或需手術 |
| 新鮮冷凍血漿 (FFP) | 全部凝血因子 | ≤ −18 °C 冷凍，約 1 年 | 多重凝血因子缺乏、大量輸血、warfarin 逆轉（無濃縮製劑時） |
| 冷凍沉澱品 (cryoprecipitate) | 纖維蛋白原、FVIII、vWF、FXIII | 冷凍 | 低纖維蛋白原血症 |

> 實際效期、保存溫度與適應症依各國法規與醫院輸血委員會規範，以上為常見標準。血小板因室溫保存，是細菌汙染風險最高的血品。

| 特殊處理 | 目的 | 適用對象 |
| --- | --- | --- |
| 減除白血球 (leukoreduction) | 減少發燒反應、HLA 致敏、CMV 傳播 | 長期輸血、移植候選人 |
| 照射 (irradiation) | 讓供血者淋巴球失去增生能力，預防 TA-GVHD | 免疫嚴重低下、造血幹細胞移植、親屬捐血 |
| 洗滌 (washing) | 去除血漿蛋白 | IgA 缺乏且有 anti-IgA、反覆嚴重過敏 |

## 輸血反應 (Transfusion Reactions)

| 反應 | 時間 | 機制 | 預防 / 處理 |
| --- | --- | --- | --- |
| 急性溶血 (AHTR) | 數分鐘–24 小時 | ABO 不相容，多因檢體或身分辨識錯誤 | 立即停止輸血；雙重核對病人與血品 |
| 非溶血性發燒 (FNHTR) | 輸血中–數小時 | 血品中的細胞激素、白血球抗體 | 減除白血球 |
| 過敏 / 過敏性休克 | 數分鐘內 | 對血漿蛋白過敏；IgA 缺乏者的 anti-IgA | 抗組織胺；嚴重者用洗滌血品 |
| 輸血相關急性肺損傷 (TRALI) | 6 小時內 | 供血者 anti-HLA / anti-HNA 活化受血者嗜中性球 | 血漿類血品優先使用男性或無懷孕史捐血者 |
| 循環負荷過重 (TACO) | 數小時內 | 容積過多；心、腎功能差者 | 控制輸注速度與量 |
| 延遲性溶血 (DHTR) | 3–14 天 | 先前致敏的抗體再次上升（回憶反應） | 查抗體史、抗體鑑定 |
| 輸血相關移植體抗宿主病 (TA-GVHD) | 1–6 週 | 供血者淋巴球攻擊受血者；致死率極高 | 照射血品 |
| 細菌汙染 / 敗血症 | 輸血中–數小時 | 血品汙染（血小板最常見） | 停止輸血、血品與病人培養 |

## 與生物資訊的關聯

| 主題 | 說明 |
| --- | --- |
| 血型基因分型 | 多數血型抗原由已知的 SNV / 結構變異決定（*ABO*、*RHD*、*RHCE*、*GYPA/GYPB*…），可從 WGS / 晶片推得，用於稀有血型捐血者篩選 |
| RHD 結構變異 | *RHD* 與 *RHCE* 高度同源，基因缺失、融合與 weak D 等位基因短讀長難以唯一比對，需專門的呼叫工具或長讀長定序，見 [定序平台](../../genomics/sequencing-techniques/sequencing-platforms.md#依應用選擇) |
| 命名 | ISBT（International Society of Blood Transfusion）維護血型系統與等位基因命名表 |
| HLA | 血小板抗輸注、TRALI 與移植配對都涉及 HLA 分型 |
