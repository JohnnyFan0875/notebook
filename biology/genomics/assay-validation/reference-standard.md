# Reference Standard

Reference standards are well-characterized materials used to benchmark assay performance during validation, verification, and quality monitoring.

## Common Uses

- Accuracy and sensitivity assessment
- Limit-of-detection studies
- Comparison across runs, operators, or platforms

## Notes

- Commercial standards may contain known variants at defined allele fractions.
- Matrix type and commutability should match the intended assay context as closely as possible.
