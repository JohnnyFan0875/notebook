# 軌跡分析 (Trajectory Analysis)

把細胞沿著一個連續的生物過程（分化、活化、藥物反應）排序。單細胞實驗只拍到一個時間點的「快照」，但不同細胞處在過程的不同階段；軌跡分析從這些快照推回過程的順序。

## 核心概念

| 概念 | 意義 |
| --- | --- |
| 擬時間 (pseudotime) | 細胞在推論路徑上的相對位置，**不是**真實時間；單位無意義、只能比較先後 |
| 根 (root) | 起點，通常需要人工指定（例：幹細胞群） |
| 分支 (branch) | 路徑分岔，暗示譜系分化 |
| RNA velocity | 由未剪接 / 已剪接 reads 的比例推估每個基因「正在上升或下降」，給軌跡方向 |

## 工具

| 工具 | 方法 | 特點 |
| --- | --- | --- |
| Slingshot（R） | 在分群上建最小生成樹，再擬合主曲線 | 簡單、穩健，需先分群 |
| Monocle 3（R） | 在 UMAP 上學習主圖 (principal graph) | 可處理複雜分支 |
| PAGA（scanpy） | 群之間的連通性圖 | 適合判斷整體拓樸，常與擴散擬時間 (DPT) 搭配 |
| scVelo（Python） | RNA velocity 的動態模型 | 提供方向；需要 spliced / unspliced 計數（velocyto、STARsolo） |
| CellRank（Python） | 結合 velocity 與相似度推估終點狀態與命運機率 | 多終點的分化系統 |

## 使用前提與陷阱

| 陷阱 | 說明 |
| --- | --- |
| 資料裡本來沒有連續過程 | 軌跡工具一定會畫出一條路徑，即使細胞只是幾個分離的群 |
| 方向是假設出來的 | 沒有 velocity 或已知標記時，起點由人決定 |
| 對 UMAP 擬合 | UMAP 會扭曲距離；在 PCA / 擴散空間推論較可靠 |
| 批次與細胞週期 | 可能被誤認成「軌跡」；先校正或回歸掉 |
| RNA velocity 的假設 | 轉錄速率恆定等假設在很多系統不成立，方向可能錯 |
| 沿擬時間的差異表現 | 用 tradeSeq 等考慮平滑曲線的方法；p 值仍有細胞非獨立的問題 |

> 軌跡是假說產生工具。用時間序列實驗、譜系追蹤 (lineage tracing) 或已知 marker 的先後順序來驗證。
