# 定序技術 (Sequencing Techniques)

不同的生物問題需要不同的定序設計：要看全基因組還是特定基因、DNA 還是 RNA、組織還是血液中的游離 DNA、bulk 還是單細胞。設計決定了資料的偏差與能回答的問題。

| 筆記 | 內容 | 回答的問題 |
| --- | --- | --- |
| [定序平台](sequencing-platforms.md) | Illumina、PacBio、ONT 等的原理與錯誤型態；2-channel 化學 | 該用短讀還是長讀？會有哪些假象？ |
| [標靶定序](targeted-panels.md) | WGS / WES / panel、amplicon vs hybrid capture、panel 內容資源 | 要定多大範圍？用哪種捕捉方式？ |
| [ChIP-seq](chip-seq.md) | 蛋白質–DNA 結合、peak calling、差異結合 | 轉錄因子 / 組蛋白修飾在哪裡？ |
| [液態切片](liquid-biopsy.md) | cfDNA、ctDNA、CTC、MRD | 能不能從血液偵測腫瘤？ |
| [單細胞 RNA-seq](single-cell-rna-seq/README.md) | 流程、QC、分群、軌跡分析 | 樣本中有哪些細胞類型與狀態？ |

引子設計見 [生資工具：引子設計](../../bioinformatics-tools/primer-design/README.md)；bulk RNA-seq 見 [RNA-seq 分析](../workflows/rna-seq/README.md)。
