# NCCN 指引 (NCCN Guidelines)

美國國家綜合癌症網絡 (NCCN) 依癌別發布的治療指引，涵蓋診斷、分期、治療流程與**生物標記檢測建議**，是腫瘤科臨床決策與健保給付最常引用的依據之一。

| 項目 | 內容 |
| --- | --- |
| 網站 | [NCCN Guidelines by cancer type](https://www.nccn.org/guidelines/category_1)（免費註冊後可閱讀） |
| 內容 | 依癌別的治療流程圖、各線治療選擇、建議檢測的生物標記（如肺癌的 *EGFR*、*ALK*、*ROS1*、*KRAS* G12C、*MET*、*RET*、*NTRK*、PD-L1） |
| 更新 | 每年多次更新；**引用時註明版本號**（如 Version 3.2025） |
| 相關指引 | NCCN 也有遺傳性癌症風險評估（*BRCA*、Lynch 症候群）與病人版指引 |

## 證據與共識分級

| 分級 | 意義 |
| --- | --- |
| Category 1 | 高層級證據，NCCN 一致共識 |
| Category 2A | 較低層級證據，一致共識（大多數建議屬此類） |
| Category 2B | 較低層級證據，多數共識 |
| Category 3 | 有重大歧見 |

## 與變異判讀的關係

| 資源 | 用途 |
| --- | --- |
| NCCN | 某生物標記在某癌別是否為標準治療依據 |
| [OncoKB](https://www.oncokb.org/) | 變異層級的治療證據分級（Level 1–4、R1–R2），整合 FDA 核准與 NCCN |
| [CIViC](../../genetics/databases/variant/civic.md) | 社群整理的變異–療效證據 |
| FDA 伴隨診斷清單 | 特定藥物必須搭配的核准檢測，見 [FDA 藥物資料庫](../../clinical-informatics-and-standards/regulatory-databases/fda-drug-database.md) |
| AMP / ASCO / CAP 分級 | 報告中體細胞變異的臨床意義分級（Tier I–IV），見 [變異判讀](../../genetics/variant-interpretation/README.md) |

> NCCN 反映美國的臨床實務；各國的給付與可用藥物不同（台灣看健保署公告與 TFDA 核准適應症）。
