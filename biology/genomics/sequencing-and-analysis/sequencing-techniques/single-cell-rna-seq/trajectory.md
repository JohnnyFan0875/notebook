# Trajectory Analysis

Trajectory analysis in single-cell RNA-seq attempts to order cells along a dynamic biological process such as differentiation, activation, or treatment response.

## Core Ideas

- Cells are arranged along inferred paths rather than real clock time.
- Pseudotime represents relative progression through the process.
- Branching trajectories can suggest lineage divergence.

## Common Tools

- Monocle
- Slingshot
- scVelo for RNA velocity-informed directionality
