# Clinical Terminology and Data Standards

This section provides concise introductions to the most important international standards used for **clinical data representation**, **interoperability**, and **regulatory submission**.
These frameworks ensure that healthcare information—ranging from lab results and medications to diagnoses and trial data—is standardized, interoperable, and reusable across systems and organizations.

## Terminology Standards

| Standard                          | Description                                                                                                                  |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| [**LOINC**](./loinc.md)           | Provides universal codes for identifying laboratory tests, measurements, and clinical observations.                          |
| [**RxNorm**](./rxnorm.md)         | Defines normalized names and relationships for clinical drugs to ensure consistency across EHR and pharmacy systems.         |
| [**SNOMED CT**](./snomed-ct.md)   | A comprehensive ontology covering diseases, findings, procedures, and other clinical concepts for semantic interoperability. |
| [**ICD-10/11**](./icd.md)         | The World Health Organization’s global standard for disease and mortality classification.                                    |
| [**CPT / HCPCS**](./cpt-hcpcs.md) | U.S. coding systems for documenting and billing medical procedures, services, and supplies.                                  |
| [**UCUM**](./ucum.md)             | A unified code system ensuring consistent representation of measurement units across systems.                                |
| [**UMLS**](./umls.md)             | Integrates multiple biomedical terminologies (LOINC, SNOMED CT, RxNorm, ICD, etc.) into a single semantic network.           |

## Data Model and Interoperability Standards

| Standard                      | Description                                                                                                                      |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| [**OMOP-CDM**](./omop-cdm.md) | A common data model developed by OHDSI to harmonize observational healthcare data for analytics and real-world evidence studies. |
| [**openEHR**](./open-ehr.md)  | An open, archetype-based framework for creating structured, semantically rich electronic health records.                         |
| [**HL7 FHIR**](./hl7-fhir.md) | A modern, web-based interoperability standard that defines RESTful APIs and modular “resources” for clinical data exchange.      |

## Clinical Research and Regulatory Standards

| Standard                            | Description                                                                                                                                |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| [**CDISC SDTM / ADaM**](./cdisc.md) | Defines how clinical trial data are collected, structured, and prepared for analysis and regulatory submission.                            |
| [**MedDRA**](./meddra.md)           | Provides hierarchical terminology for coding and analyzing adverse events and medical conditions in clinical trials and pharmacovigilance. |
