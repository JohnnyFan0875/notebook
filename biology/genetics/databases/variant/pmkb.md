# PMKB (Precision Medicine Knowledgebase)

Weill Cornell Medicine 的腫瘤變異知識庫：由病理醫師與腫瘤科醫師針對「基因 + 變異 + 腫瘤類型 + 組織」撰寫臨床解讀文字並分級，可直接作為報告解讀的參考範本。

| 項目 | 內容 |
| --- | --- |
| 網站 | [pmkb.weill.cornell.edu](https://pmkb.weill.cornell.edu/) |
| 內容 | 依腫瘤類型與組織分別撰寫的解讀、分級、參考文獻 |
| 何時用 | 撰寫腫瘤 NGS 報告時，參考同類變異的解讀寫法 |
| 對照 | [CIViC](civic.md)（開放、證據層級細）、OncoKB（療效分級）、[COSMIC](cosmic.md)（突變頻率） |
