# BRCA Exchange

彙整全球 *BRCA1* / *BRCA2* 變異資料的平台，整合 ClinVar、LOVD、BIC 等來源，並顯示 **ENIGMA 聯盟**（ClinGen 認可的 *BRCA1/2* 專家小組）的分類。

| 項目 | 內容 |
| --- | --- |
| 網站 | [brcaexchange.org](https://brcaexchange.org/) |
| 介面 | 一般版只顯示專家審閱過的分類；研究者版顯示所有來源的資料與衝突 |
| 何時用 | 遺傳性乳癌 / 卵巢癌（HBOC）變異判讀；確認是否有 ENIGMA 專家分類 |
| 判讀準則 | ENIGMA 制定的 *BRCA1/2* 專用 ACMG 調整版（ClinGen VCEP 規格） |

> *BRCA1/2* 的分類直接影響預防性手術與 PARP 抑制劑用藥；有專家小組分類時以它為準，見 [ACMG/AMP：基因專一規則](../../variant-interpretation/acmg-amp.md#clingen-svi-的重要修訂)。
