# COSMIC (Catalogue Of Somatic Mutations In Cancer)

Wellcome Sanger Institute 維護的最大體細胞突變資料庫，整合人工整理的文獻與大型腫瘤定序計畫，提供突變在各癌別的出現次數、癌症基因與突變特徵。

| 項目 | 內容 |
| --- | --- |
| 網站 | [cancer.sanger.ac.uk/cosmic](https://cancer.sanger.ac.uk/cosmic) |
| 授權 | 學術用途註冊後免費；商業使用需付費授權；下載需登入 |
| 主要模組 | COSMIC Mutation（突變與樣本）、**Cancer Gene Census (CGC)**、Cancer Mutation Census (CMC)、[Mutational Signatures](../../../genomics/cancer-genomics/mutational-signatures.md)、Actionability、Cell Lines Project |

| 模組 | 用途 |
| --- | --- |
| 突變頁面 | 某突變在多少樣本、哪些癌別出現（熱點判斷） |
| Cancer Gene Census | 有充分證據參與癌症的基因清單：Tier 1（強證據）、Tier 2；標示致癌基因 / 抑癌基因角色 |
| Cancer Mutation Census | 依證據把突變分級，整合功能預測與頻率 |

> COSMIC 收錄的是「在腫瘤中觀察到」的突變，包含大量乘客突變 (passenger)；出現在 COSMIC 不代表是驅動突變，更不代表 germline 致病。體細胞變異的臨床意義用 AMP / ASCO / CAP 分級評估，療效證據查 [CIViC](civic.md)、OncoKB。
