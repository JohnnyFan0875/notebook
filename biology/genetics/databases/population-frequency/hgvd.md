# HGVD (Human Genetic Variation Database)

京都大學建立的日本族群遺傳變異與等位基因頻率資料庫，另提供 eQTL 資料，可用於東亞族群的變異判讀。

| 項目 | 內容 |
| --- | --- |
| 網站 | [hgvd.genome.med.kyoto-u.ac.jp](https://www.hgvd.genome.med.kyoto-u.ac.jp/index.html) |
| 資料 | 日本人的變異與等位基因頻率；近期文獻包含 3,135 人 WGS（2025）、4,344 人（2026 更新） |
| 基因組版本 | 原生為 GRCh37 / hg19；GRCh38 與 T2T-CHM13 以 liftOver 提供 |
| 其他 | eQTL 軌道與 cis-eQTL 批次下載、基因型計數 |
| 維護 | 持續更新（2026 年釋出 v3.1）；商業授權由 GenoConcierge Kyoto 處理 |

> 同樣是日本族群、規模更大的資源是東北醫療 Megabank 的 jMorp（數萬人 WGS）；東亞族群頻率可同時參考 [TaiwanGenomes](taiwangenomes.md) 與 [gnomAD](gnomad.md) 的 EAS 群。
