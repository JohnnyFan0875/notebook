# TaiwanGenomes

以台灣人體生物資料庫 (Taiwan Biobank) 中 1,496 位台灣人的全基因組定序建立的變異瀏覽資料庫，提供台灣族群的等位基因頻率與註解。

| 項目 | 內容 |
| --- | --- |
| 網站 | [genomes.tw](https://genomes.tw/#/) |
| 資料 | 1,496 人 WGS（分三批定序：496、497、503 人），平均 30×；以 GATK 流程呼叫，附 VQSR tranche 與註解 |
| 可查 | 依基因、區域、變異篩選；台灣族群的等位基因頻率 |
| 文獻 | [Complete genomic profiles of 1,496 Taiwanese reveal curated medical insights（medRxiv）](https://www.medrxiv.org/content/10.1101/2021.12.23.21268291v1.full) |
| 何時用 | 台灣病人的變異判讀：gnomAD 東亞樣本中台灣人很少，某些在台灣常見的變異（創始者效應）在 gnomAD 中看起來很罕見 |
