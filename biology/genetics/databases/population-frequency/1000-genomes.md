# 1000 Genomes Project

第一個大規模描繪人類遺傳多樣性的計畫（2008–2015），提供 26 個族群的公開基因型。現由 IGSR（International Genome Sample Resource）維護。

| 項目 | 內容 |
| --- | --- |
| 網站 | [internationalgenome.org](https://www.internationalgenome.org/)、[資料入口](https://www.internationalgenome.org/data) |
| 樣本 | Phase 3：2,504 人、26 個族群、5 個超族群（AFR、AMR、EAS、EUR、SAS）；NYGC 以 30× 重新定序擴充至 3,202 人（含親子三人組，GRCh38） |
| 東亞族群 | CHB（北京漢人）、CHS（南方漢人）、CDX（傣族）、JPT（日本）、KHV（越南京族） |
| 授權 | 完全公開、無使用限制 |

| 用途 | 說明 |
| --- | --- |
| 教學與方法開發 | 樣本與族群標籤被大量工具與教材使用 |
| 填補 (imputation) 參考 | 早期 GWAS 的標準參考族群 |
| 族群結構 / 祖源推估 | PCA 投影的參考點 |
| 細胞株 | 樣本有 Coriell 細胞株可購買（如 NA12878，見 [GIAB](../../../genomics/assay-validation/reference-standard.md#genome-in-a-bottle-giab)） |

> 族群頻率判讀優先用規模大得多的 [gnomAD](gnomad.md)；1000 Genomes 的價值在於個體層級的公開基因型與族群標籤。
