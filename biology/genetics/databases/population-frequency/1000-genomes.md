# 1000 Genomes Project

The 1000 Genomes Project is a reference dataset of human genetic variation across multiple global populations.

## Useful For

- Looking up common population variants
- Comparing allele frequencies across continental ancestry groups
- Using public reference genotypes for teaching, benchmarking, and method development

## Access

- Website: [https://www.internationalgenome.org/](https://www.internationalgenome.org/)
- Data portal: [https://www.internationalgenome.org/data](https://www.internationalgenome.org/data)

## Notes

- 1000 Genomes is smaller than gnomAD but remains useful because samples and population labels are widely used in examples and tools.
- Frequency estimates should be interpreted with ancestry, sample size, and genome build in mind.
