# ClinPGx（原 PharmGKB）

史丹佛的藥物基因體知識庫。2025 年 PharmGKB 與 CPIC、PharmCAT 整合為 **ClinPGx**，`pharmgkb.org` 已永久轉址到 `clinpgx.org`；CPIC 指引仍保留自己的名稱，PharmVar 則維持獨立、由 ClinPGx 引用。

| 項目 | 內容 |
| --- | --- |
| 網站 | [clinpgx.org](https://www.clinpgx.org/)（原 [pharmgkb.org](https://www.pharmgkb.org/)） |
| 臨床註解 (clinical annotations) | 變異–藥物關聯的摘要，附證據等級 |
| 仿單註解 (drug label annotations) | FDA、EMA、PMDA 等仿單中的 PGx 資訊 |
| 指引註解 | CPIC、DPWG 等指引的整理 |
| 其他 | 變異註解（個別文獻）、藥物動力學 / 藥效學通路圖 |
| 工具 | PharmCAT：從 VCF 推出 star allele、表型與 CPIC 建議 |

## 臨床註解的證據等級

| 等級 | 意義 |
| --- | --- |
| 1A | 有 CPIC / 醫學會指引或已在臨床實施，且有支持證據 |
| 1B | 多個研究重複且有顯著關聯，證據強 |
| 2A | 中度證據，且變異位於已知重要的藥物基因 (VIP) |
| 2B | 中度證據 |
| 3 | 證據有限：單一研究或結果不一致 |
| 4 | 只有個案、非顯著研究或體外 / 分子研究 |

> 臨床決策以 1A / 1B 與正式指引為主；低等級註解只代表有文獻提及。推出處方建議見 [CPIC](cpic.md)。
