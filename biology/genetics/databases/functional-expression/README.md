# Functional and Expression Databases

Functional and expression databases help interpret what a gene or variant might do biologically: where the gene is expressed, which pathway it belongs to, what the protein does, and which external resources support those annotations.

- [Human Protein Atlas](../../../molecular-biology/molecular-databases/human-proteome-atlas.md)

## Notes

- Expression and pathway evidence is contextual. It supports biological plausibility but usually does not prove clinical causality by itself.
- Record tissue, cell type, dataset version, and gene identifier when expression evidence is used.
