# HGMD (Human Gene Mutation Database)

英國卡地夫大學整理的資料庫，收錄**已發表文獻**中報告與人類遺傳疾病相關的 germline 變異。

| 項目 | 內容 |
| --- | --- |
| 網站 | [hgmd.cf.ac.uk](https://www.hgmd.cf.ac.uk/) |
| 版本 | Public（學術註冊免費，資料延遲數年、功能有限）；Professional（付費訂閱，即時更新、可下載） |
| 何時用 | ClinVar 沒有記錄的變異，檢查文獻是否曾報告 |

| 分類 | 意義 |
| --- | --- |
| DM | 疾病致病突變（文獻作者如此主張） |
| DM? | 可能致病，證據有疑問 |
| DP / DFP / FP | 與疾病相關的多型性 / 有功能證據的多型性 / 有功能但無疾病關聯 |
| R | 已撤回 |

> HGMD 的 "DM" 反映的是**文獻作者的主張**，不是依 ACMG 準則的分類；不少早期報告的 DM 變異後來在 gnomAD 中頻率過高而被重新分類為良性。一定要回到原始文獻，確認表型、遺傳模式與證據，再依 [ACMG/AMP](../../variant-interpretation/acmg-amp.md) 判讀。使用付費版時記錄版本與授權。
