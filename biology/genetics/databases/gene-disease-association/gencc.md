# GenCC (Gene Curation Coalition)

把多個機構（ClinGen、Orphanet、Genomics England PanelApp、OMIM 及多家臨床實驗室）的基因–疾病有效性評估，統一成同一套分級並放在一起比較。

| 項目 | 內容 |
| --- | --- |
| 網站 | [search.thegencc.org](https://search.thegencc.org/) |
| 分級 | Definitive、Strong、Moderate、Supportive、Limited、Disputed、Refuted、Animal model only、No known relationship |
| 下載 | 全部評估的表格（含提交者、疾病 ID、遺傳模式、日期） |
| 何時用 | 一次看「各機構怎麼評這個基因」；ClinGen 尚未評估的基因可參考其他機構 |

> 各提交者的標準不同：專家小組（ClinGen）與商業實驗室的評級可信度不一；分級不一致時，回到各自的證據摘要。
