# GeneReviews

華盛頓大學編輯、放在 NCBI Bookshelf 的遺傳疾病臨床總覽，由領域專家撰寫並經同儕審閱，偏向臨床實務。

| 項目 | 內容 |
| --- | --- |
| 網站 | [ncbi.nlm.nih.gov/books/NBK1116](https://www.ncbi.nlm.nih.gov/books/NBK1116/) |
| 下載 | [FTP](https://ftp.ncbi.nlm.nih.gov/pub/GeneReviews/)：章節與基因 / OMIM 的對照表 |
| 每章內容 | 診斷標準、臨床特徵、基因型–表型相關、鑑別診斷、處置與監測、遺傳諮詢（再發風險）、檢測策略 |

| 何時用 | 說明 |
| --- | --- |
| 確認表型是否相符（PP4） | 看臨床特徵與診斷標準 |
| 檢測策略 | 該先做單基因、panel 還是 MLPA？常見的致病變異類型與比例 |
| 報告與諮詢 | 處置建議、再發風險 |
| 基因型–表型 | 特定變異是否對應特定表型或嚴重度 |

> 章節更新時間不一，注意每章的最後修訂日期。
