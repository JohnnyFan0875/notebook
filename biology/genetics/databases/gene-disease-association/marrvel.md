# MARRVEL (Model organism Aggregated Resources for Rare Variant ExpLoration)

Baylor College of Medicine 開發的罕病變異探索工具：輸入一個人類基因或變異，一頁整合人類遺傳資料與模式生物資源，幫助評估候選基因 / 變異是否有生物學依據。

| 項目 | 內容 |
| --- | --- |
| 網站 | [marrvel.org](https://marrvel.org/) |
| 輸入 | 基因符號，或基因 + 變異（HGVS / 座標） |
| 人類資料 | OMIM、ClinVar、gnomAD、DGV、DECIPHER、Geno2MP、GTEx |
| 模式生物 | 小鼠 (MGI)、果蠅 (FlyBase)、線蟲 (WormBase)、斑馬魚 (ZFIN)、酵母 (SGD、PomBase) 的表型與表現 |
| 其他 | DIOPT 同源基因預測、多物種蛋白序列比對（看變異位置是否保守） |

| 何時用 | 說明 |
| --- | --- |
| 新的候選疾病基因 | 人類資料少時，模式生物的表型是重要的功能證據 |
| 錯義變異 | 跨物種保守性：該胺基酸在演化上是否不變 |
| 規劃功能實驗 | 找出有現成突變株的模式生物 |

> 網站為動態頁面，本筆記內容依開發團隊的說明整理；目前整合的資料來源以網站為準。
