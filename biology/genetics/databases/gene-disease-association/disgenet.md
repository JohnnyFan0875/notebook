# DisGeNET (DISGENET)

整合人工審閱資料庫（UniProt、ClinGen、ClinVar、Orphanet 等）、GWAS、動物模型與**文獻探勘**結果的基因–疾病、變異–疾病關聯平台，涵蓋孟德爾與複雜疾病。

| 項目 | 內容 |
| --- | --- |
| 網站 | [disgenet.com](https://disgenet.com/) |
| 指標 | GDA score（依來源數量與類型給分）、Evidence Index、疾病專一性指標 |
| 存取 | 網頁、REST API、R 套件、Cytoscape app |
| 授權 | 學術、非營利研究與教學可申請**免費學術授權**；任何與商業產品相關的使用都需商業授權（[授權說明](https://support.disgenet.com/support/solutions/articles/202000087487-do-i-need-a-commercial-license-can-i-use-disgenet-data-in-my-product-)） |

| 適合 | 不適合 |
| --- | --- |
| 研究探索、建立候選基因清單、疾病網路分析 | 臨床判讀的證據：文獻探勘的關聯可能只是共同出現在摘要中 |

> 依來源過濾（只看 curated 來源）可提高可信度；臨床用途改看 [ClinGen](clingen-validity.md) / [GenCC](gencc.md)。
