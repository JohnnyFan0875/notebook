# Orphanet

歐洲主導的罕見疾病與孤兒藥知識庫，提供罕病的標準命名與分類、基因關聯、盛行率、臨床指引，以及各國的專家中心、檢測實驗室與病友組織名錄。

| 項目 | 內容 |
| --- | --- |
| 網站 | [orpha.net](https://www.orpha.net/) |
| 編碼 | ORPHA code（如 `ORPHA:558` Marfan 症候群）；與 ICD-10 / ICD-11、OMIM、SNOMED CT 對照 |
| 開放資料 | [Orphadata](https://www.orphadata.com/)：疾病清單、基因關聯、表型（HPO）、盛行率、流行病學，免費下載 |
| 何時用 | 罕病的標準名稱與分類、盛行率（計算 ACMG BS1 的頻率門檻）、病人資源 |

> 罕見疾病在 ICD 中常沒有專屬代碼，ORPHA code 可補足病歷與登錄資料的編碼，見 [ICD](../../../clinical-informatics-and-standards/clinical-terminology/icd.md)。
