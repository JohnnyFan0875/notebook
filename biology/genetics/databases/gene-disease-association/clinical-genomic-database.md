# CGD (Clinical Genomic Database)

NHGRI 院內研究部門人工整理的資料庫，只收錄**有可行臨床介入措施**的遺傳疾病基因，用來判斷一個基因結果是否「可處置」(actionable)。

| 項目 | 內容 |
| --- | --- |
| 網站 | [research.nhgri.nih.gov/CGD](https://research.nhgri.nih.gov/CGD/)（最後更新 2025-02-24） |
| 每筆資料 | 基因、疾病、等位疾病、遺傳模式、介入適用年齡（兒童 / 成人）、臨床分類、介入措施與理由 |
| 分類 | 19 個器官系統的表現類別；介入類別另加藥物基因體 |
| 範圍 | 單基因與部分雙基因疾病；不含連續基因缺失症候群、複雜疾病的易感因子、體細胞變異 |
| 用途 | 研究用：WES / WGS 的次要發現 (secondary findings) 篩選、決定哪些結果值得回報 |

> 網站註明供研究使用，不作為臨床指引。臨床上回報次要發現的基因清單，依 ACMG Secondary Findings 清單（定期更新）為準。
