# GeneCards

Weizmann Institute 維護的基因摘要入口，把上百個資料來源（NCBI、UniProt、OMIM、GTEx、通路、藥物、文獻）彙整到每個基因的一頁。

| 項目 | 內容 |
| --- | --- |
| 網站 | [genecards.org](https://www.genecards.org/) |
| 適合 | 快速了解陌生基因：別名、功能摘要、表現、疾病、通路、相關藥物 |
| 相關工具 | MalaCards（疾病版）、VarElect（依表型排序候選基因） |
| 限制 | 二手彙整；正式判讀要回到原始資料庫（OMIM、ClinGen、UniProt）；大量下載與商業使用需授權 |
