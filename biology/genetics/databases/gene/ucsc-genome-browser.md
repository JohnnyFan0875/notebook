# UCSC Genome Browser

The UCSC Genome Browser is an interactive genome browser for viewing genome assemblies, gene tracks, regulatory annotations, comparative genomics, and custom tracks.

## Useful For

- Visual inspection of gene location, exon structure, repeats, conservation, and regulatory tracks
- Checking coordinates in a specific genome build
- Uploading BED, VCF, BAM, bigWig, and other custom tracks
- Downloading annotation tables through the Table Browser

## Access

- Website: [https://genome.ucsc.edu/](https://genome.ucsc.edu/)
- Table Browser: [https://genome.ucsc.edu/cgi-bin/hgTables](https://genome.ucsc.edu/cgi-bin/hgTables)
- Downloads: [https://hgdownload.soe.ucsc.edu/downloads.html](https://hgdownload.soe.ucsc.edu/downloads.html)

## Notes

- Confirm whether coordinates are zero-based or one-based when moving between browser views, BED files, and reports.
- Save genome build and track versions when screenshots or exported tables are used as evidence.
