# Ensembl

Ensembl is a genome annotation resource for genes, transcripts, variants, comparative genomics, and regulatory features across many species.

## Useful For

- Reviewing gene models, transcript structures, exons, and genomic coordinates
- Checking variant annotations and links to tools such as Variant Effect Predictor
- Comparing genome builds and annotations across species
- Downloading GTF, FASTA, BioMart, REST, and FTP data for analysis workflows

## Access

- Website: [https://www.ensembl.org/](https://www.ensembl.org/)
- BioMart: [https://www.ensembl.org/biomart/](https://www.ensembl.org/biomart/)
- REST API: [https://rest.ensembl.org/](https://rest.ensembl.org/)
- FTP: [https://ftp.ensembl.org/pub/](https://ftp.ensembl.org/pub/)

## Notes

- Always record the Ensembl release and genome build.
- Transcript-specific interpretation should include transcript ID and version when available.
- For human clinical work, compare with MANE Select or RefSeq when transcript choice matters.
