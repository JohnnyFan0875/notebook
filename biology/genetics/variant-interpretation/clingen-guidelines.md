# ClinGen 變異判讀指引 (ClinGen Variant Classification Guidance)

ClinGen 為 ACMG/AMP 2015 準則補上細部規則：每條準則何時適用、能給到什麼強度。這些建議原由 **Sequence Variant Interpretation (SVI) 工作組**發布；SVI 已於 **2025 年 4 月退役**，相關建議彙整在 ClinGen 的 Variant Classification Guidance 頁面。

| 項目 | 連結 |
| --- | --- |
| SVI 工作組（已退役，保留歷史文件） | [clinicalgenome.org/working-groups/sequence-variant-interpretation](https://clinicalgenome.org/working-groups/sequence-variant-interpretation/) |
| 基因專一規格 (VCEP specifications) | [CSpec Registry](https://cspec.genome.network/) |
| 專家小組在 ClinVar 的分類 | [ClinVar expert panels FTP](https://ftp.ncbi.nlm.nih.gov/pub/clinvar/ClinGen/expert_panels/) |

## SVI 建議一覽

| 主題 | 年份 | 重點 |
| --- | --- | --- |
| 準則修飾命名 | 2017 | 調整強度的寫法，如 `PM2_Supporting`、`PVS1_Strong` |
| PVS1 | 2018（2024 可編輯決策樹） | 依變異類型、NMD、是否在關鍵 exon / 區域決定強度 |
| BA1 | 2018 | 頻率 > 5% 為獨立良性證據，並列出例外變異清單 |
| 可信來源 (PP5 / BP6) | 2018 | 建議不再使用 |
| 貝氏框架 / 計分制 | 2018；計分制 2020 | 準則轉成點數，見 [ACMG/AMP：計分版](acmg-amp.md#計分版貝氏框架) |
| PS2 / PM6（新生變異） | 2018，2021 更新 | 依表型專一性與親子確認給點 |
| PS3 / BS3（功能試驗） | 2019 | 試驗需經驗證；依對照變異數量給強度 |
| PM3（反式） | 2019 | 依同時觀察到的致病變異分級與次數計分 |
| PM2 | 2020 | 預設降為 Supporting |
| PP3 / BP4 校準 | 2022 | 單一校準工具依分數給到 Strong，見 [in-silico 預測](in-silico-prediction.md) |
| PP1 / BS4、PP4 | 2023 | 共分離計分；表型專一性 |
| 剪接 | 2023 | 預測與 RNA 觀察的剪接影響如何對應 PVS1 / PS3 / PP3 / BP7 |
| 非編碼區變異 | — | 調控區、深層 intron 變異的判讀 |

> 有 VCEP 規格的基因（如 *BRCA1/2*、*TP53*、*PTEN*、*MYH7*、*RASopathy* 基因），以該規格取代通用準則。準則本體見 [ACMG/AMP 分級](acmg-amp.md)。
