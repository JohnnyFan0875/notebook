# ACGS 最佳實務指引 (ACGS Best Practice Guidelines)

英國臨床基因體科學學會 (Association for Clinical Genomic Science) 發布的實驗室指引。最常用的是罕病變異分級指引：在 ACMG/AMP 架構上整合 ClinGen SVI 建議並給出英國實務的具體做法，是**計分制**實際應用的重要參考。

| 項目 | 內容 |
| --- | --- |
| 網站 | [acgs.uk.com：Best Practice Guidelines](https://www.acgs.uk.com/quality/best-practice-guidelines/) |
| 罕病變異分級 | *ACGS Best Practice Guidelines for Variant Classification in Rare Disease*，最新 **2024 v1.2**（2020 版已於 2024-02 退役） |

## 其他相關文件

| 文件 | 用途 |
| --- | --- |
| General Genetic Laboratory Reporting Recommendations（v1.1，2020） | 報告格式與用語 |
| Guidance for the Analysis of Structural Variants from WGS Data | 全基因組資料的 SV / CNV 分析 |
| Classification of Oncogenicity of Somatic Variants in Cancer（v1.1，SVIG-UK） | 體細胞變異的致癌性分級 |
| Targeted NGS（2015）、NGS Bioinformatics（2016） | 標靶定序與生資流程的品質要求 |
| Internal Quality Control（2015） | 實驗室內部品管 |

> 各機構指引大方向一致（都以 ACMG/AMP 為基礎），細節（如 PM2 強度、計分門檻、特定準則的組合限制）略有差異；報告中註明採用的指引與版本。ACGS 指引內容需下載 PDF 查閱，本筆記只整理文件清單與版本。

相關：[ACMG/AMP 分級](acmg-amp.md)、[ClinGen 指引](clingen-guidelines.md)、[檢測確效](../../genomics/assay-validation/README.md)。
