# 遺傳學 (Genetics)

人類遺傳學的基本概念、資料庫與變異判讀：從一個基因或變異出發，查它是什麼、與哪些疾病有關、在族群中多常見、預測會造成什麼影響，最後依指引判讀臨床意義。定序與分析流程見 [基因體學](../genomics/README.md)。

## 建議順序

```
基礎概念（VAF、創始者效應、新生變異）→ 資料庫查詢 → 變異判讀（HGVS 命名 → 預測工具 → ACMG/AMP 分級）
```

| 模組 | 內容 | 回答的問題 |
| --- | --- | --- |
| [基礎概念](foundations/README.md) | 變異等位基因頻率、創始者效應、新生變異 | VAF 怎麼算？族群頻率為何與盛行率不同？ |
| [資料庫](databases/README.md) | 基因、基因–疾病、變異、族群頻率、藥物基因體、表現量 / 通路 | 這個基因 / 變異查哪裡？ |
| [變異判讀](variant-interpretation/README.md) | HGVS 命名、in-silico 預測、ACMG/AMP、ClinGen、ACGS | 這個變異是致病的嗎？ |
