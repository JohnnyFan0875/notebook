# Primer Designing Criteria — Editable Board

| Category                     | Criteria                                                                                         |
| ---------------------------- | ------------------------------------------------------------------------------------------------ |
| **Primer Length**            | 18–25 bp                                                                                         |
| **Amplicon Length**          | Typical 120–180 bp; Common 140–160 bp; Max <250 bp                                               |
| **GC Content**               | 40–60%                                                                                           |
| **Melting Temperature (Tm)** | 55–65°C; F/R Tm difference ≤ 2°C                                                                 |
| **SNP Avoidance**            | Primer binding sites must avoid common SNPs; ≥50 bp from rs site unless assay requires otherwise |
| **Structure Checks**         | No strong hairpins (ΔG < –2); avoid self-/cross-dimers, especially at 3′ end                     |
| **Specificity (BLAST/UCSC)** | Only one significant hit in Homo sapiens; extra hits OK only if same gene family                 |
| **Repeat Regions**           | Avoid homopolymers and tandem repeats                                                            |
| **3′ End Design**            | Last 7 bases are critical; avoid hairpins and 3′ complementarity                                 |
