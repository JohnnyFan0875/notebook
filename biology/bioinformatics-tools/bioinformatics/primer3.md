# Primer3

Primer3 is a widely used tool for designing PCR primers for DNA amplification.

## Key Features

- Designs primer pairs from a target sequence
- Supports constraints for product size, melting temperature, and GC content
- Useful for PCR, qPCR, sequencing, and cloning workflows
