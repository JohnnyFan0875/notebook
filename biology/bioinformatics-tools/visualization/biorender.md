# BioRender

網頁版科學示意圖工具：拖放大量生物圖示（細胞、蛋白、器材、器官），用模板快速畫出機制圖、實驗流程與 graphical abstract。

| 項目 | 內容 |
| --- | --- |
| 網站 | [biorender.com](https://www.biorender.com/) |
| 適合 | 訊號路徑、實驗流程、分子機制、簡報與論文示意圖 |
| 不適合 | 資料圖表（用 ggplot2 / matplotlib，見 [視覺化](README.md)） |
| 授權 | 免費版只能個人 / 教學使用且有浮水印；**投稿發表需付費方案取得授權**，並依期刊要求在圖說註明 "Created with BioRender.com" |
| 替代 | Inkscape（免費向量繪圖）+ [Bioicons](https://bioicons.com/) / Servier Medical Art（CC BY 圖示）、Affinity Designer、Adobe Illustrator |
