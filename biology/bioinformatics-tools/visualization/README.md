# 視覺化工具 (Visualization Tools)

| 工具 | 用途 | 何時用 |
| --- | --- | --- |
| [IGV](igv.md) | 目視檢查 BAM / VCF / BED / 覆蓋度 | 確認候選變異、檢查比對假象、看剪接 |
| [BioRender](biorender.md) | 科學示意圖（機制、流程、graphical abstract） | 簡報、論文圖 |

資料圖表（volcano、heatmap、PCA）用程式產生，見 [ggplot2](../../../data-science/data-manipulation-and-eda/visualization/ggplot2.md) 與 [資料視覺化](../../../data-science/data-manipulation-and-eda/visualization/README.md)；基因體區間瀏覽也可用 [UCSC Genome Browser](../../genetics/databases/gene/ucsc-genome-browser.md)。
