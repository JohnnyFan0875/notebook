# IGV

Integrative Genomics Viewer (IGV) is a desktop visualization tool for inspecting aligned reads, variants, and genomic annotations.

## Common Inputs

- BAM or CRAM for alignments
- VCF for variants
- BED or GTF for annotations

## Useful Tasks

- Manually review candidate variants
- Inspect coverage, strand bias, and mapping context
- Compare multiple tracks in the same locus
