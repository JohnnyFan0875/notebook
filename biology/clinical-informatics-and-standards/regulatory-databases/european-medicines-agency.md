# 歐洲藥品管理局 (European Medicines Agency, EMA)

歐盟負責藥品科學評估、監督與安全監測的機構。經集中審查程序 (centralised procedure) 的藥品由 EMA 評估、歐盟執委會核准，在全歐盟有效；癌症、罕病、生物製劑等多數新藥都走這條路。

| 項目 | 內容 |
| --- | --- |
| 網站 | [ema.europa.eu](https://www.ema.europa.eu/en/homepage)、[藥品查詢](https://www.ema.europa.eu/en/medicines) |
| 涵蓋 | 集中審查的人用、動物用藥與草藥資訊；各國自行核准的藥品要查各國藥品登錄 |
| 何時用 | 比較美歐核准狀態與適應症、讀評估報告中的療效與安全性資料 |

## 主要資源

| 資源 | 內容 |
| --- | --- |
| Medicine finder | 依藥名或成分查詢集中審查藥品；每個藥有 EPAR (European Public Assessment Report)，含產品特性摘要 (SmPC) |
| 進階搜尋 | 所有程序，包含被拒絕或撤回的申請 |
| 資料下載 | 藥品資料的 Excel 表 |
| 審查中藥品 | CHMP 正在評估的人用藥，每月更新 |
| [adrreports.eu](https://www.adrreports.eu) | EudraVigilance 的疑似不良反應通報（公開彙總） |
| 臨床試驗 | 歐盟臨床試驗資訊（CTIS） |

> EPAR 的評估報告常比仿單更詳細地說明療效證據與審查爭議，適合了解一個藥「為什麼被核准、附帶哪些條件」（如 conditional marketing authorisation）。

美國的對應資源見 [FDA 藥物資料庫](fda-drug-database.md)。
