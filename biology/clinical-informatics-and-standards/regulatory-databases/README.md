# 法規資料庫 (Regulatory Databases)

主管機關公開的藥品核准、仿單與伴隨診斷資料。精準醫療常要回答「這個藥在哪裡核准、適應症是什麼、要搭配哪個檢測」，這些都以官方資料庫為準。

| 資源 | 用途 | 何時用 |
| --- | --- | --- |
| [FDA 藥物資料庫](fda-drug-database.md) | Drugs@FDA、伴隨診斷清單、首次學名藥核准 | 查美國核准日期、仿單、指定的伴隨診斷 |
| [European Medicines Agency](european-medicines-agency.md) | 歐盟集中審查藥品、EPAR、不良反應通報 | 查歐盟核准狀態與評估報告 |
| [Elsevier Healthcare Hub](elsevier-healthcare-hub.md) | 罕見疾病教育內容（非法規資料） | 罕病入門閱讀 |

## 美國 vs 歐盟

| 問題 | 美國 (FDA) | 歐盟 (EMA) |
| --- | --- | --- |
| 藥品核准與仿單 | Drugs@FDA、DailyMed（仿單 SPL） | Medicine finder、EPAR（含 SmPC） |
| 學名藥 / 生物相似藥 | Orange Book（治療等效）、Purple Book（生物製劑） | EPAR 中標示 generic / biosimilar |
| 伴隨診斷 | CDx 清單 | 依 IVDR 由 notified body 審查，EMA 參與諮詢 |
| 不良反應 | FAERS（openFDA API） | EudraVigilance（adrreports.eu） |
| 試驗登錄 | ClinicalTrials.gov | CTIS / EU Clinical Trials Register |

> 台灣的藥品許可證與仿單查詢用衛福部食藥署 (TFDA) 的西藥、醫療器材許可證資料庫；健保是否給付另見 [健保支付標準](../clinical-terminology/taiwan-nhi-service-standards.md)。

癌症治療指引（NCCN）見 [NCCN](../../genomics/cancer-genomics/nccn.md)；藥物 × 基因型的用藥建議見 [藥物基因體資料庫](../../genetics/databases/pharmacogenomics/README.md)。物質安全資料表 (SDS) 與分析證明書 (COA) 已移到 [檢驗醫學：物質安全與品質](../../laboratory-medicine/material-safety-and-quality/README.md)。
