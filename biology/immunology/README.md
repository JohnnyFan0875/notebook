# 免疫學 (Immunology)

免疫細胞的亞群、標記與細胞激素，以及它們在腫瘤與檢體分析中的意義。做 PBMC / 腫瘤的單細胞定序、流式細胞術或免疫治療生物標記時，這些是註解細胞類型與判讀結果的基礎。

建議順序：T / B 細胞亞群 → 細胞激素網路 → 免疫標記 → PBMC、腫瘤浸潤淋巴球（應用）
