### React Overview

**React** is a JavaScript **library** for building component-based UIs.

**Core principles:**

1. **Declarative** – describe _what_ UI should look like, not _how_ to update it.
2. **Component-Based** – reusable, isolated units of UI.
3. **Unidirectional Data Flow** – predictable updates and state management.

**Ecosystem:**

- UI Library: React itself.
- Routing: React Router.
- State Management: Redux, Zustand, Recoil.
- Framework Integration: Next.js for SSR/SSG support.

```bash
# Example: create a new React project
npx create-react-app my-app
cd my-app
npm start
```
