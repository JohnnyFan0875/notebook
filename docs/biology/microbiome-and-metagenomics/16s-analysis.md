# 16S Analysis

16S rRNA analysis profiles bacterial communities by sequencing conserved ribosomal gene regions rather than total community DNA.

## Common Targets

- `V3-V4` amplicons are widely used because they balance taxonomic resolution and sequencing practicality.
- Full-length or near-full-length 16S can improve resolution when the platform supports it.

## Typical Workflow

- DNA extraction
- Amplicon generation and sequencing
- Read denoising or clustering
- Taxonomy assignment and diversity analysis

## Common Tools

- QIIME 2
- DADA2
