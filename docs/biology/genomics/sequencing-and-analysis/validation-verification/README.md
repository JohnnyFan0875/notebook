# Validation and Verification

Validation and verification are related but distinct quality activities in molecular testing workflows.

## Overview

- Validation asks whether a new method is fit for its intended use.
- Verification confirms that an established method performs as expected in the local setting.

## Typical Review Areas

- Accuracy and precision
- Limit of detection
- Reportable range
- Reference materials and controls
- Bioinformatics pipeline performance
