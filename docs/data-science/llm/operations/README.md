# Operations

This module covers the operational side of LLM systems: testing, deployment, monitoring, and iterative improvement after launch.

Key point: A useful LLM application is not finished when the prompt works once. It needs an operating model for versioning, evaluation, deployment, and production feedback.

## Notes in This Module

| Note | Focus |
| --- | --- |
| [Operating Agent Systems](operating-agent-systems.md) | modularity, robustness, monitoring, retries, fallback design, and deployment choices for scalable agents |
| [LLMOps](llmops.md) | prompt management, testing, deployment, observability, drift, and feedback loops |

Tip: Most production failures come from weak operational discipline rather than from raw model capability alone.
