# Packages

這個章節把 package 語法與概念教材分開，避免在剛學模型觀念時被 API 細節淹沒。當你已經知道「為什麼要做」，再回來查「在套件裡怎麼做」會更有效率。

## Packages

- [scikit-learn](scikit-learn/README.md): [pipeline](../workflow/pipeline-basic.md)-oriented API for predictive modeling
- [statsmodels](statsmodels/README.md): statistical inference, summaries, and diagnostics

## When to Use This Section

- You already understand the concept and want package-specific syntax
- You want to compare APIs across packages
- You want implementation notes that do not belong to the conceptual path

## 建議用法

- 先讀概念頁，例如 [regularization](../foundations/regularization.md) 或 [logistic regression](../supervised-learning/classification/logistic-regression.md)。
- 再進入 package 筆記，確認 API、常見參數、輸出物件與診斷方式。
