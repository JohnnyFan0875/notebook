# Training Workflows

模型真的能不能訓練成功，往往不取決於你有沒有更大的架構，而是取決於訓練流程是否穩定、能否恢復、是否會過擬合，以及能否善用預訓練權重。

## Core Questions

- 我如何保存模型，讓之後能穩定續訓或推論？
- 資料不多時，什麼時候該 freeze、什麼時候該 fine-tune？
- 當模型與資料變大時，如何提升訓練效率而不把流程搞壞？
